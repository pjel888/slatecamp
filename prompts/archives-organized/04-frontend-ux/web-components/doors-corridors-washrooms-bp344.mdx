export const DoorConfigurator = () => {
  const [width, setWidth] = useState(900)
  const [space, setSpace] = useState(1800)
  const [thresh, setThresh] = useState(0)
  const [hwH, setHwH] = useState(900)
  const [force, setForce] = useState(2.0)
  const issues = [], passes = []
  if (width < 900) issues.push('Clear width ' + width + 'mm < 900mm minimum (C.2.1)')
  else passes.push('Width ' + width + 'mm ✓')
  if (space < 1800) issues.push('Approach space ' + space + 'mm < 1,800mm minimum (C.2.6) — 2024 updated')
  else passes.push('Approach space ' + space + 'mm ✓')
  if (thresh > 12) issues.push('Threshold ' + thresh + 'mm exceeds 12mm maximum (C.3.1) — 2024 updated, was 19mm')
  else if (thresh > 6) passes.push('Threshold ' + thresh + 'mm ✓ — bevel required (gradient 1:8)')
  else passes.push('Threshold ' + thresh + 'mm ✓')
  if (hwH < 800 || hwH > 1000) issues.push('Hardware height ' + hwH + 'mm outside preferred 800–1,000mm range (C.2.11)')
  else passes.push('Hardware ' + hwH + 'mm ✓')
  if (force > 2.0) issues.push('Door closer force ' + force + 'kg exceeds 2.0kg maximum (C.2.4) — 2024 updated, was 4.0kg')
  else passes.push('Door closer ' + force + 'kg ✓')
  const ok = issues.length === 0
  const sc = 0.09, wX = 30, wY = 40, wH = 120
  const dPx = Math.min(width * sc, 80), spW = Math.min(space * sc, 120), tH = Math.min(thresh * 0.8, 8)
  const hardY = wY + wH - (hwH * sc), dSX = wX + 10, dEX = dSX + dPx
  const wOk = width >= 900, sOk = space >= 1800, tOk = thresh <= 12
  const fields = [
    { label: 'Clear width (mm)', val: width, set: setWidth, min: 500, max: 1200, step: 10 },
    { label: 'Approach space (mm)', val: space, set: setSpace, min: 900, max: 2400, step: 100 },
    { label: 'Threshold height (mm)', val: thresh, set: setThresh, min: 0, max: 25, step: 1 },
    { label: 'Hardware height (mm)', val: hwH, set: setHwH, min: 600, max: 1200, step: 50 },
    { label: 'Closer force (kg)', val: force, set: setForce, min: 0.5, max: 5.0, step: 0.1 },
  ]
  return (
    <div style={{ fontFamily: "Inter, system-ui, sans-serif", border: '1px solid #d0cec7', borderRadius: 10, padding: '20px 24px', margin: '20px 0', background: '#F8F7F5' }}>
      <div style={{ fontFamily: "'DM Mono', monospace", fontSize: 10, textTransform: 'uppercase', letterSpacing: '0.08em', color: '#1B3FC4', marginBottom: 8 }}>Interactive — Door Compliance Configurator (2024 IRR)</div>
      <p style={{ fontSize: 13, color: '#444', margin: '0 0 14px' }}>Enter your door parameters. All values are checked against the 2024 Revised IRR.</p>
      <div style={{ display: 'flex', gap: 14, flexWrap: 'wrap', marginBottom: 14 }}>
        {fields.map(({ label, val, set, min, max, step }) => (
          <div key={label}>
            <label style={{ display: 'block', fontSize: 11, fontWeight: 600, color: '#555', marginBottom: 4, textTransform: 'uppercase' }}>{label}</label>
            <input type="number" value={val} min={min} max={max} step={step} onChange={e => set(parseFloat(e.target.value) || 0)} style={{ width: 100, padding: '7px 9px', border: '1.5px solid #ccc', borderRadius: 6, fontSize: 13, fontFamily: "'DM Mono', monospace" }} />
          </div>
        ))}
      </div>
      <div style={{ borderRadius: 8, padding: '12px 14px', fontSize: 12, lineHeight: 1.8, marginBottom: 12, background: ok ? '#e8f5ee' : '#fdf0ef', border: `1px solid ${ok ? '#1B7A3C' : '#E63329'}`, color: ok ? '#0f4a24' : '#5a1a16' }}>
        {ok

      </div>

# Doors, Corridors & Washrooms — BP 344 / RA 9442

This article covers the specific dimensional requirements for accessible doors, corridors, and washrooms under BP 344 (Accessibility Law). **All values reflect the 2024 Revised IRR** — effective August 8, 2024 — which contains major dimensional changes from earlier versions. Values that changed from the 2013 Illustrated IRR are flagged with `⟳ 2024 UPDATED`. Read the exam patterns and common mistakes first.

---

## How It's Tested

Three ALE patterns apply to this topic. Knowing them before you read the dimensions tells you which numbers to memorize and which traps to watch for.

**Pattern 1 — Direct recall of dimensions.** "What is the minimum clear opening width for an accessible door under BP 344?" Answer: **900 mm**. Exact values required — 850 mm will be marked wrong.

**Pattern 2 — Scenario application.** "An architect is designing an accessible toilet cubicle. The space available is 1.70 m × 1.80 m. Does this meet BP 344 requirements?" Answer: No — the 2024 IRR requires **1,800 mm × 1,800 mm** (a square). Students who memorized the old 1,700 × 1,800 mm will fail this question.

**Pattern 3 — Code violation identification (Area C).** A floor plan shows an accessible washroom layout. You must identify violations — a grab bar at the wrong height, a door swinging inward, a corridor too narrow, a threshold too high. This rewards understanding *why* each dimension exists, not just memorizing the number.

---

## Common Mistakes

The ten most frequent errors. Read these before the dimensions.

**1. Using outdated corridor width.** The 2024 IRR raised the single-wheelchair + ambulant corridor from 1,200 mm to **1,500 mm** (C.5.1). Students using older review materials will get this wrong.

**2. Thinking the cubicle is rectangular.** The 2024 IRR changed the toilet cubicle to **1,800 × 1,800 mm** — it is now a square. The old 1,700 × 1,800 mm is superseded. Do not use it.

**3. Using the wrong threshold maximum.** The 2024 IRR lowered the threshold maximum to **12 mm** (from 19 mm). If a threshold is higher than 6 mm, it must be beveled. Students still memorizing 19 mm will fail threshold questions.

**4. Getting the clear level space at doors wrong.** The 2024 IRR increased the clear level space to **1,800 × 1,800 mm** (from 1,500 × 1,500 mm) before and beyond every door (C.2.6). The exception: where a door opens onto but not into a corridor, the corridor side may be reduced to **1,500 mm**.

**5. Mixing up grab bar height reference points.** The L-type grab bar must be exactly **300 mm** above the top of the toilet seat — the 2024 IRR dropped the old 280–300 mm range to a single value. Since the WC seat is at 450 mm above the floor, the grab bar top is at approximately **750 mm** above finished floor.

**6. Confusing WC centerline from the wall.** The 2024 IRR explicitly states: WC centerline shall be **450 mm** from the finished face of the sidewall (C.6.3.d). The grab bar outer face to wall is **100 mm**, and the grab bar face to WC centerline is **350 mm** (C.6.3.c).

**7. Wrong urinal lip height.** The 2024 IRR changed the urinal maximum lip height from 480 mm to **350–400 mm from toilet floor** (C.6.12) — a drop of 80–130 mm.

**8. Door swing in accessible toilets.** Accessible toilet stall doors must swing **outward** — so a rescuer can open the door if a person has fallen behind it. Locks must be openable from outside with a coin (C.6.14).

**9. Turnabout dimensions.** The 2024 IRR changed corridor turnabouts to **1,800 × 1,800 mm** (from 1,500 × 1,500 mm). The maximum spacing between turnabouts remains 12,000 mm.

**10. Door closer force.** The 2024 IRR lowered interior door closer maximum force to **2.0 kg** (from 4.0 kg).

## Legislative Framework

Three laws work together to govern accessibility in Philippine buildings.

**Batas Pambansa Blg. 344 (1982)** — the Accessibility Law. It requires buildings, institutions, establishments, and public utilities to install facilities that enhance the mobility of persons with disabilities (PWDs). The DPWH administers it; city/municipal engineers enforce it through the building permit process.

**Republic Act No. 7277 (1992)** — the Magna Carta for Disabled Persons. The overarching rights-based law guaranteeing PWDs the right to accessible transportation, buildings, and public spaces.

**Republic Act No. 9442 (2007)** — amends RA 7277 by adding enforcement penalties. First violation: ₱50,000 to ₱100,000 fine or 6 months to 2 years imprisonment. Subsequent violations: ₱100,000 to ₱200,000 or 2 to 6 years imprisonment.

The **2024 Revised IRR** (effective August 8, 2024, Official Gazette Vol. 120 No. 28, pp. 7192–7205 + Appendix A) is the current technical standard. It was jointly promulgated by DPWH Secretary Manuel M. Bonoan and DOTr Secretary Jaime J. Bautista, in coordination with NCDA Chairman Rexlon T. Gatchalian.

## Accessible Entrances

All public entrances shall be accessible, including those serving leased spaces, parking facilities, pedestrian tunnels, and elevated walkways (C.1.1). All entrances and exits along the accessible route shall prevent longer travel distances or exclusion of PWDs from the standard path (C.1.2).

Where entrances are not level with site arrival grade, accessible ramps, wheelchair lifts, or similar mechanisms shall be provided (C.1.3).

**Vestibules** ⟳ 2024 UPDATED: Level area of at least **1,800 mm depth × 1,800 mm width** (C.1.4). Old value: 1,800 × 1,500 mm.

**Glass doors and panels:** Horizontal or graphical patterns with a minimum luminance contrast of 30%, between **800 mm and 1,500 mm** above the floor (C.1.5).

**Weather protection:** Accessible entrances/exits, including stairs, ramps, and wheelchair lifts, shall have full weather protection from rain and heat exposure (C.1.6).

> **Source:** BP 344 2024 Revised IRR, Part C, Section 1 — Accessible Entrances
