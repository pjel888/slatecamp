02 · Architectural Diagram Language
Edges + Material Hierarchy

The SEQUENCE.DENSE and site model references both achieve their architectural diagram quality through one mechanism: clean dark edges on light forms. This overrides photorealism as the design target.

Required
Edges on every structural mesh. Threshold 15°. Color #3A3A3A (dark charcoal, not black). Line width 1.0. Scale 1.002 to prevent z-fighting. This single change transforms 3D from "app" to "architectural diagram."
Visual
Context buildings use ghost white + edges only. Material: #EDEAE4, roughness 0.85, no shadows cast (castShadow: false). They recede visually, making the active element dominate.
Visual
Active/proposed element uses SlateCamp cobalt. #1B3FC4, roughness 0.4, metalness 0.0. Add Outlines (thickness 0.02) in a slightly lighter blue when selected.
Required
Lighting rig is architectural studio, not dramatic. Warm key #FFF5E6 from upper-right at 1.2 intensity. Cool fill #E6EFFF opposite at 0.4. Ambient 0.35. Matches how physical architectural models are photographed.
// Reusable architectural mesh — use for ALL building volumes function ArchMass({ geometry, color = '#EDEAE4', isActive = false, ...props }) { return ( <mesh geometry={geometry} castShadow receiveShadow {...props}> <meshStandardMaterial color={color} roughness={isActive ? 0.4 : 0.85} /> <Edges threshold={15} color="#3A3A3A" lineWidth={1.0} scale={1.002} /> {isActive && <Outlines thickness={0.02} color="#4A6FE8" screenspace={false} />} </mesh> ) }

04 · Interaction Architecture
Module Layout & UX Patterns

One layout template applied consistently across all 3D modules. Desktop = side panel, mobile = bottom sheet. Canvas is always full-bleed.

/* Module layout template (desktop) ┌──────────────────────────────────────────────────┐ │ ← Module title [?] [Grid] [Reset] │ ← 48px header ├─────────────────────────┬────────────────────────┤ │ │ PARAMETERS │ │ │ ─ Lot area │ │ 3D CANVAS │ ─ Footprint % │ │ Sky: #EEF2FA │ ─ Floors │ │ Ground: #D4CFC4 │ │ ← 320px side panel │ │ RESULTS │ │ │ TGFA PSO AMBF BHL │ │ │ │ │ │ CODE REFERENCE │ │ │ PD 1096 Rule 7 │ │ │ [→ Open Wiki] │ ├─────────────────────────┴────────────────────────┤ │ Mobile: Draggable bottom sheet with controls │ ← collapses on mobile └──────────────────────────────────────────────────┘ */
Interaction
Violation feedback is immediate and spatial. When a slider causes a code violation, the violating geometry turns red and pulses. A violation banner appears in the side panel. The student sees cause (slider) and effect (geometry) simultaneously.
Interaction
6 hotspots maximum per view. Positioned ON the element they describe. Categories: cobalt = code requirement, amber = dimension, red = violation (never decorative). Tap to expand. Tap canvas to dismiss.
Interaction
Camera: isometric-style preset on load. Position [8, 8, 8], fov 35, orbit target [0, 1.5, 0]. Constrained: maxPolarAngle π/2 (no below-floor), minDistance 3, maxDistance 25. The SEQUENCE.DENSE 3/4 elevated view is the default.
Performance
frameloop="demand" on all modules. Render only on interaction. Call invalidate() on every slider change, hotspot open, and orbit gesture. Target: 30fps mobile, 60fps desktop. Triangle budget per module: <30K.
05 · Narrative Layer · Inspired by SEQUENCE.DENSE
Step-Through Mode for site-development-controls

The SEQUENCE.DENSE poster is a 6-step narrative. The site-development-controls model should have the same. A guided tour that builds the scene step by step, with each step unlocking one development control concept.

Step 00 · Locate
Read the lot
  • Show the raw ground plane only
  • Lot boundary in dashed line appears
  • Hotspot: "This is your lot area (PSO denominator)"
  • Camera zooms to lot extent
Step 01 · Setbacks
Carve the margins
  • Amber wireframe boxes appear at edges
  • Setback dimensions annotated
  • Hotspot: "Front setback min 3.0m — PD 1096"
  • Buildable area highlighted in green fill
Step 02 · AMBF
Find the footprint
  • Max AMBF footprint extruded as flat slab
  • AMBF % shown in HUD
  • Slider activated: drag to see PSO impact
  • Violation pulse if AMBF exceeded
Step 03 · Build Height
Rise within limits
  • Building extrudes upward floor by floor
  • BHL ceiling plane shown as dashed horizontal
  • TGFA counter increments live
  • Height violation turns mass red
Step 04 · Open Space
Give back the ground
  • PSO requirement highlighted green on site
  • ISA calculated and shown
  • Context buildings appear (ghost white)
  • Site feels complete and massed
Step 05 · Sandbox
Test your limits
  • All sliders unlocked
  • Live violation detection on all parameters
  • In-canvas quiz: "What is the max TGFA?"
  • Link: Open Wiki → Rule 7 & 8
