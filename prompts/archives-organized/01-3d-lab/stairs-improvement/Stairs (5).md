### 2.3 BP 344 – Accessibility Law

Operates as an **overlay** on top of NBCP or BP 220 where a route is designated accessible; enforced via DPWH and LGUs. [dpwh.gov](https://www.dpwh.gov.ph/dpwh/sites/default/files/laws_codes_orders/BP_344_IRR_0.pdf)

Stairs along accessible routes must satisfy: [dpwh.gov](https://www.dpwh.gov.ph/dpwh/sites/default/files/laws_codes_orders/amended_irr_bp_344_official_gazette_2.pdf)

- **Clear width**  
  - Accessible route width commonly **≥ 1.20 m**, and up to **1.50 m** in many practice references. [dpwh.gov](https://www.dpwh.gov.ph/dpwh/sites/default/files/laws_codes_orders/BP_344_IRR_0.pdf)
- **Riser & tread**  
  - Many BP 344 guides recommend **150 mm max** riser and **300 mm min** tread for accessible stairs (consistent with global ergonomic best practice), though the IRR often defers to the base stair code while tightening usability and width. [scribd](https://www.scribd.com/document/759362468/BP-344-Updated-Version)
- **Landings**  
  - **Minimum** clear landing length for accessible route stairs: **1.50 m**. [dpwh.gov](https://www.dpwh.gov.ph/dpwh/sites/default/files/laws_codes_orders/amended_irr_bp_344_official_gazette_2.pdf)
  - Clear level spaces (≥1.20 m) at top and bottom. ### 4.2 Evaluation Algorithm (Pseudo)

```ts
function evaluateStair(stair, projectTags: string[], rules: StairRule[]) {
  const baseRules = rules.filter(
    r => r.overlay_type === "base" &&
    r.applies_to.some(tag => projectTags.includes(tag))
  );

  const overlayRules = rules.filter(
    r => r.overlay_type === "overlay" &&
    r.applies_to.some(tag => projectTags.includes(tag))
  );

  const allRules = [...baseRules, ...overlayRules];

  const evaluations = allRules.map(rule => {
    const actual = measureFromStair(stair, rule.dimension_type);
    const result = checkConstraint(rule, actual);

    return {
      rule_id: rule.id,
      law: rule.law,
      dimension_type: rule.dimension_type,
      constraint_type: rule.constraint_type,
      required_value_mm: rule.value_mm ?? { min: rule.min_mm, max: rule.max_mm },
      actual_value_mm: actual,
      passes: result.passes,
      severity: classifySeverity(rule, result),
      explanation: buildExplanation(rule, result)
    };
  });

  const conflicts = detectConflicts(evaluations, rules);

  return { evaluations, conflicts };
}
```

- **`classifySeverity`**: choose severity by law (e.g., RA 9514 failure = *critical*, BP 220 violation in non-BP 220 project = *invalid*, BP 344 failure along accessible route = *critical*). [elibrary.judiciary.gov](https://elibrary.judiciary.gov.ph/thebookshelf/showdocs/2/13859)
- **`detectConflicts`**: group rules by `dimension_type` and see if multiple applicable laws impose incompatible ranges; mark *strictest* as “effective” and others as “more permissive / more restrictive”.
