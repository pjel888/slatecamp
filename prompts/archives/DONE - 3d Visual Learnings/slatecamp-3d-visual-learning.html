SlateCamp · UX Research Brief · Visual & 3D Learning
How Architecture Students Actually Learn Spatially — and What That Means for the 3D Lab
Research-backed insights on visual cognition, spatial learning, building code comprehension, and how to make the 3D Lab the most effective part of SlateCamp's pedagogical system.
The Problem
Architecture is inherently spatial. The ALE tests it abstractly. That gap is where students fail.
ALE candidates spend 90% of their review time reading flat text: reviewer PDFs, photocopied notes, printed codes. But the exam tests spatial understanding — setbacks, stair dimensions, ramp slopes, structural bays, travel distances. You cannot fully understand the National Building Code by reading it. You need to see it.
Key Research Finding
ALE topnotchers consistently cite this: "The trend of questions is more analytical and technical, rather than just purely objective. You have to answer it as an architect and think like one." (Fritz Sendrijas, ALE June 2023 Topnotcher #1, Ateneo de Davao). They drew diagrams. They mapped processes. They visualized the code. SlateCamp's 3D Lab gives every student that visual thinking tool — not just topnotchers who naturally think that way.

Spatial ability — the capacity to mentally visualize, rotate, and reason about 3D objects — is a strong predictor of performance in architecture and engineering education (Porat & Ceobanu, 2024). Students with higher spatial ability perform significantly better on ALE-adjacent tasks: reading floor plans, understanding structural systems, applying code setback rules.

The critical insight: spatial ability is trainable. The research literature is clear that structured 3D practice — interactive models, cutaway sections, parametric manipulation — measurably improves spatial reasoning. This isn't just about "making learning fun." It's about building a cognitive skill the ALE actually tests.

"The 3D Lab isn't supplementary. For subjects like Building Codes and Structural Systems, it is the most direct path to understanding that transfers to the exam."
Section 01 · The Science
Research Foundations for 3D Visual Learning in Architecture
What the research says — translated directly into product decisions for the 3D Lab.
01
🧠
Dual-Channel Processing (Mayer, 2001)
The brain processes visual and verbal information through separate cognitive channels. When a student both sees a 3D model AND reads the code citation simultaneously, both channels are engaged — retention is significantly higher than reading alone. This is why the 3D Lab's hotspot system (visual + text) is pedagogically correct: it's not decoration, it's dual-coding in action.
Cognitive Theory of Multimedia Learning · Effect size d=0.60–0.90
→ SlateCamp 3D Lab Application
Every hotspot must show both the 3D visual context AND the exact code text simultaneously. Never just one or the other. The split view (model left, code right) is the optimal layout for code comprehension.
02
⚗️
Worked Example Effect (Sweller, 1988)
Novice learners learn faster from studying a complete worked example than from solving problems independently. However, as expertise develops, this reverses — experts learn better from problems than from examples (Expertise Reversal Effect). Architecture students early in their review = novices for most code topics. They need to see the correct application first.
Cognitive Load Theory · Sweller · Effect size d=0.57
→ SlateCamp 3D Lab Application
This validates the 3-phase progression already planned: Guided Tour (expert shows) → Faded Example (student fills one parameter) → Full Sandbox (student configures from brief). The sequence matches the learning curve perfectly.
03
🔄
Spatial Training Transfers to Exams
2024 studies on architecture and engineering students found that structured spatial training programs — combining 3D models, interactive manipulation, and mental rotation exercises — significantly improved domain-specific spatial ability. The key finding: improvement was largest when training used domain-specific materials (building elements, floor plans) rather than abstract shapes. ALE-specific 3D models will transfer more than generic spatial training.
Porat & Ceobanu, Educ. Sci. 2024 · Domain-specific training outperforms generic
→ SlateCamp 3D Lab Application
Every model must use real Philippine building elements at real code dimensions. A stairway at exactly 180mm risers / 280mm treads (PD 1096) — not a "generic stairway." This specificity is what makes the spatial training transfer directly to exam questions.
04
📐
Contiguity Principle — Proximity of Visual + Text
Mayer's contiguity principle: people learn better when corresponding words and pictures are presented simultaneously, adjacent to each other — not separated across screens. When the code citation and the model are on different screens (or require scrolling to see both), the cognitive load of maintaining both in working memory increases dramatically, reducing comprehension.
Mayer, 2009 · Spatial & Temporal Contiguity · Reduces extraneous cognitive load
→ SlateCamp 3D Lab Application
Code citations must appear as inline overlays or split-panel — never on a separate page. On mobile: code text appears below the model in the same scroll view. On desktop: side-by-side panel. The student's eye should never have to leave the model to read the relevant code.
05
⚡
Signaling Principle — Guide Attention Deliberately
Adding visual cues (arrows, highlights, outlines) that direct attention to the critical element in a complex visual significantly reduces cognitive load and improves comprehension (Mayer & Fiorella, 2014). In a complex 3D model, students' attention can scatter. A red highlight on the relevant dimension guides working memory to what matters — exactly like a professor pointing at the board.
Signaling principle · Mayer & Fiorella · Reduces split-attention effect
→ SlateCamp 3D Lab Application
During guided tours, auto-highlight the dimension being explained: an animated arrow pointing to the riser height, a pulsing outline on the accessible door width. Never leave the student scanning a complex model to "find the relevant part." Direct them.
06
🎮
Active Manipulation Beats Passive Viewing
Students who actively manipulate 3D models (rotate, adjust parameters, trigger states) show significantly better spatial understanding and retention than students who watch an instructor manipulate the same model. The act of controlling the model creates a stronger mental representation. This is why the parametric sandbox is pedagogically superior to a video walkthrough of the same content.
Petersen, Petkakis & Makransky, 2022 · Immersion + interactivity drive VR learning
→ SlateCamp 3D Lab Application
The guided tour is for orientation only (Phase 1 of learning). The real learning happens in the faded example and sandbox phases. Design the UX so students feel compelled to touch the sliders — lower the friction to interaction, don't make the model feel "hands off."
Section 02 · ALE-Specific Research
Which ALE Topics Most Need Visual Learning — and Why
Not all ALE topics benefit equally from 3D visualization. This map prioritizes the 3D Lab modules by their visual learning impact — meaning: how much does seeing it in 3D unlock understanding that text alone cannot provide?
ALE Topic / Code
Why Spatial Learning Matters Here
Visual Impact
PD 1096 — Stairway Dimensions
Riser, tread, headroom, handrail height
Students memorize numbers (180mm riser, 280mm tread) without understanding what they look like at scale. An ALE question about non-compliant stairs is incomprehensible if you've never seen a compliant one. A 3D stairway you can adjust makes the code physical.
CRITICAL
RA 9514 — Fire Code Travel Distance
Exit travel distance, corridor widths, occupancy loads
"45-meter travel distance" is abstract text until you see it drawn on a floor plan. A 3D floor plan where red zones appear when the travel distance exceeds the code limit makes the rule spatial and memorable — not a number to memorize.
CRITICAL
BP 344 — Accessibility Law
Ramp slopes, door widths, toilet clearances, parking bays
Dimensionally dense. Multiple rules interact spatially: the slope of a ramp, its landing length, the clear width. A 3D accessible toilet with adjustable dimensions — turn it red when non-compliant — encodes these rules as spatial constraints, not a list of numbers.
CRITICAL
PD 1096 — Setbacks & Site Coverage
AMBF, PSO, TGFA, setback lines
This is pure site geometry. Students struggle with AMBF calculations because they can't visualize how setback lines, lot coverage, and building footprint interact. A parametric site model where adjusting lot size or building placement recalculates AMBF in real time makes this computational.
CRITICAL
NSCP 2015 — Structural Bays
Beam/column relationships, span ratios, reinforcement
Structural framing is inherently 3D. Reading about beam-column connections in text produces minimal understanding. A structural bay model where you can see the frame, apply loads, and watch the member selection change based on spans is worth 50 pages of reviewer notes.
HIGH
History — Classical Orders
Doric, Ionic, Corinthian, Tuscan, Composite
Students confuse orders because they're memorizing names-to-descriptions. Side-by-side 3D columns with labeled components (entasis, fluting, capital type, proportion) makes the differences visually obvious — and memorable in a way text descriptions never are.
HIGH
Building Utilities — MEPFS Systems
Plumbing stacks, electrical routing, fire suppression
MEP systems are invisible in buildings — hidden in walls and ceilings. Students read about them without ever seeing how they're spatially organized within a building. A cutaway 3D building revealing the MEP layers makes these abstract systems concrete.
HIGH
PD 957 / BP 220 — Subdivision Planning
Road widths, open space ratios, lot dimensions
Subdivision standards involve area calculations and spatial relationships that benefit from a site-level visualization. Less urgent than individual building codes, but parametric site planning tools have high comprehension payoff.
MEDIUM
Professional Practice — Fee Structures
SPP Documents, percentage fees, project stages
Primarily text-based knowledge. Tables and diagrams in the Wiki are more appropriate than 3D models. Visual learning impact for this topic is low — use 2D infographics in the Wiki instead of 3D resources.
LOW
Prioritization Principle
Build 3D modules for topics where the spatial relationship IS the learning objective (setbacks, stair geometry, travel distances, structural bays, MEP routing). Don't build 3D models for topics that are fundamentally text-based (fees, ethics, legislation). The question to ask for each module: "Can a student understand this without seeing it?" If yes → Wiki is sufficient. If no → 3D Lab is necessary.
Section 03 · UX Framework
The 3-Phase Learning Model for Every 3D Module
Based on Cognitive Load Theory's Worked Example Effect and the Expertise Reversal principle. Every module in the 3D Lab should follow this three-phase arc — not necessarily in one session, but across a student's progression from first encounter to mastery.
The SlateCamp 3D Learning Arc
Cognitive Load Theory Applied to Architecture Code Learning
Phase 01 · Novice
Guided Tour
Expert walks through the complete compliant example. Student watches and reads. No decisions required. Goal: build initial mental schema with minimum cognitive overload.
Example: Stairway module — tour shows each dimension labeled, explains why each rule exists. Student never touches a slider.
Phase 02 · Developing
Faded Example
Model is pre-configured with one parameter left blank. Student must supply the missing value. System provides feedback. Goal: retrieve and apply knowledge with minimal decision load.
Example: "Set the correct riser height for this stairway. Hint: check PD 1096 Rule 7." Student sets slider → model shows compliant or non-compliant state.
Phase 03 · Proficient
Full Sandbox
Student receives a building brief ("Design a fire exit stairway for a 6-story commercial building"). All parameters open. Model responds in real time. Goal: transfer learning to novel application.
Example: "Configure a compliant stairway for this occupancy type." Model turns red on violations with specific code citations. Student adjusts until compliant.
Why This Sequence Matters
The ALE doesn't ask students to recite the riser height. It asks: "Which of these stairway configurations complies with PD 1096?" That requires the ability to evaluate a configuration against code — a higher-order spatial skill. The full sandbox phase is what trains this. Students who only do Phase 1 (read the Wiki) or Phase 2 (flashcard the numbers) will recognize the correct answer but can't derive it. Phase 3 is where exam-level performance is built.
Section 04 · UX Design Principles
10 UX Principles for the 3D Lab Interface
Each principle is grounded in cognitive science and tested against the ALE candidate's specific context: mobile-first Filipino architecture student, often on 4G, potentially doing this at night, under moderate time pressure.
1
One Concept Per Session — Never Let the Model Get Complex Before the Concept is Understood
Cognitive load research is clear: when a model shows too many elements simultaneously, working memory overloads and comprehension drops. The BP 344 toilet model should focus on ONE clearance dimension per session — not all six simultaneously. Reveal complexity progressively.
UX pattern: "Focus Mode" toggle that highlights one dimension at a time, greying out the rest. Guided tour always starts in Focus Mode. Student can unlock "Full View" after completing the guided tour.
Split-attention effect · Cognitive Load Theory · Mayer's Segmenting Principle
2
Code Violations Must Be Visually Unmistakable — Red Is Not Enough
Color cannot be the only violation indicator (accessibility, colorblindness). But more importantly, the violation state should feel viscerally wrong — not just "red model." The building should look wrong — cramped, blocked, dangerous — so the student develops intuition, not just memorization.
When a dimension is non-compliant: (1) model element turns Signal Red, (2) a dimension callout appears with the current value vs the required value, (3) a brief text explains the consequence: "At 150mm, this riser is non-compliant. A person cannot climb this comfortably and safely." Make the violation feel real, not just flagged.
Embodied cognition research — physical consequences increase code retention vs abstract rules
3
Real Dimensions at Real Scale — Always
A stairway rendered at 50% scale provides no spatial intuition about whether the dimensions are appropriate. The moment the student adjusts a slider, the model must respond at life-scale. 1 meter in the model = 1 meter in the physical world. This is what builds spatial calibration — the ability to "feel" whether a dimension is right.
All models render with a scale reference (a silhouette of a standing person at 1.7m). When a door width is set to 700mm, the person silhouette barely fits — the visual makes the code rationale self-evident. This is what no PDF or flashcard can replicate.
Scale cognition research — spatial learning requires metric calibration, not just dimensional recall
4
Connect Every Model to a Specific Past ALE Question Type
ALE candidates are exam-motivated. They need to see the direct connection between the 3D model and the question format on the actual board exam. "This is how ALE Question Type 3 on Building Technology looks in 3D" is more motivating than "explore this model."
Each module card in the 3D Lab shows: "This module covers: X questions per ALE sitting, typically appearing as [question type]." After the sandbox phase, show a Camp Mode quiz session filtered to that exact topic — immediately connecting the 3D understanding to the question format. The sequence: See it in 3D → Answer questions about it.
Transfer of learning — learning is most effective when training conditions match test conditions
5
Let Students Break the Building — Then Teach Them Why
Students learn better from making and correcting errors than from observing correct examples alone (Error-based learning, Metcalfe, 2017). The parametric sandbox's violation feedback system is most effective when students actively make wrong configurations and then see why they're wrong — not just configure correct ones.
In sandbox mode: add a "Challenge Mode" button that presents the student with a deliberately non-compliant building and asks them to identify all violations. "Find 3 code violations in this stairway." This turns the model into an active diagnostic tool — the same cognitive skill the ALE tests in its analytical questions.
Error-based learning · Metcalfe, 2017 · Desirable difficulty principle
6
The Hotspot Question Must Come Before the Answer — Always
The testing effect applies to 3D learning: being asked a question before revealing the answer produces deeper encoding than reading the answer first. In-canvas quizzing (hotspot-based questions) should appear before the dimension label reveals — not after. "What should the riser height be here?" → student guesses → correct value appears with code citation.
Hotspot interaction sequence: (1) Hotspot pulsates on a dimension point. (2) Student taps. (3) Question appears: "What is the minimum required handrail height?" (4) Student selects from options OR enters a value. (5) Correct value appears with code citation. Never show the label first then ask the question — that's passive reading, not retrieval.
Testing Effect · Roediger & Karpicke, 2006 · Retrieval strengthens memory better than re-reading
7
Mobile-First With Intentional Rotation — Desktop Is Secondary
SlateCamp's primary user is on a mid-range Android phone. 3D WebGL on mobile is technically possible with React Three Fiber, but requires intentional UX choices to feel good rather than janky. The biggest risk: students trying to manipulate a 3D model on a small screen feel frustrated rather than engaged.
Specific mobile UX decisions: (1) Default to a fixed, flat "exploded diagram" view on mobile — not a full 3D orbit. (2) Offer a "3D View" button that enables full orbit only when the student explicitly wants it. (3) Sliders for parametric controls (not drag-on-model — too imprecise on small screens). (4) Orientation lock prompt: "Rotate your phone for the best view" for models that genuinely benefit from landscape.
Philippine device context: median device is Realme/Samsung A-series, 6" screen, 4G — performance optimization is a UX decision, not just technical
8
Context Narration — Give the Model a Story, Not Just Dimensions
Numbers without context are forgotten. Numbers embedded in a story (a building type, a client scenario, a real Philippine project) are remembered. "This is a typical residential stairway in a PD 957 socialized housing project" creates a richer encoding than "stairway with compliant dimensions."
Each module opens with a 2-sentence scenario: "You're reviewing plans for a 4-story commercial building in Quezon City. The building inspector has flagged the fire exit stairway. Here's what they found." This converts an abstract code exercise into a professional practice scenario — closer to how the ALE's hardest analytical questions are framed.
Context-dependent memory · Tulving, 1983 · Narrative encoding improves recall vs isolated fact learning
9
The Classical Orders Module Deserves Special Treatment — Visual Identity, Not Just Dimensions
ALE History questions on Classical Orders aren't testing dimension recall — they're testing visual identification. "Which order is shown in this photograph?" Questions show images and students must identify the column type by visual characteristics. A 3D model approach must prioritize visual distinctiveness training — not parametric exploration.
Special interaction pattern for History modules: (1) Side-by-side comparison of all 5 orders simultaneously. (2) "Spot the Order" quiz: show a single column, student identifies it. (3) Highlight the distinctive feature when wrong: "The capital gives it away — look at the volutes." (4) Progressive elimination: show increasingly similar pairs (Doric vs Tuscan, Ionic vs Corinthian) to sharpen discrimination.
Discrimination learning · Signal detection theory · Visual similarity increases error rates without explicit comparison training
10
Track 3D Lab Engagement in the Mastery Engine — Not Separately
If 3D Lab interactions don't feed the Heatmap and Readiness Score, students will perceive it as optional "enrichment" rather than core study. The moment the Heatmap shows a node moving from grey to amber after a 3D Lab session, the module becomes part of the core study loop — not an optional extra.
Every completed 3D Lab module + hotspot quiz should write to user_interactions and update user_node_mastery for the relevant topic_id. In-canvas questions should count toward the question bank — same mastery weight as Camp Mode questions, potentially with a small visual-learning bonus weight (students who see the concept in 3D AND answer questions correctly have demonstrated deeper understanding).
Attribution theory — students invest more in activities they see affecting their outcomes. Heatmap change is the visible payoff.
Section 05 · Module-Level UX Patterns
Specific Interaction Design for Priority Modules
Concrete UX recommendations for the top 5 priority 3D Lab modules. These go beyond general principles into specific interaction decisions.
PD 1096 — Stairway Configurator
Code Compliance
The most common Building Technology question type. Students memorize "180mm riser, 280mm tread" without understanding why — and without being able to evaluate non-compliant configurations. This module must build evaluation ability, not just recall.
GUIDED
Narrated fly-through of a compliant stairway. Animated labels appear sequentially: riser height → tread depth → clear width → headroom clearance → handrail height. Person silhouette walks up the stairs at the end. Code section cited for each dimension.
FADED
"This stairway has 3 compliant dimensions and 1 non-compliant. Find it." Sliders locked except for the non-compliant one. Student adjusts until compliant. Model changes color from partial red to full green.
SANDBOX
"Design a fire exit stairway for a 6-story assembly occupancy building." All sliders open. Occupancy type selector affects required clear width. Model shows real-time compliance status. "Export Configuration" button for notes.
IN-CANVAS
3 hotspot questions on the compliant model: "What would happen if the riser was increased to 250mm?" (multiple choice). "What code section governs handrail height?" "At what riser height does this stairway become non-compliant for residential use?"
RA 9514 — Fire Code: Travel Distance Floor Plan
Code Compliance
Travel distance is a 2.5D problem — it's a floor plan calculation with spatial consequences. Students fail this because they try to memorize maximum distances as isolated numbers, not as spatial constraints on a real floor plan.
GUIDED
Interactive floor plan (top-down view). A red "danger zone" radius emanates from the furthest occupied point. As the guide narrates, a path animates from the farthest point to the nearest exit. Distance counter shows current vs maximum. When non-compliant, the floor plan turns amber-to-red progressively.
FADED
"Place the exit door so that all occupied areas are within the travel distance limit." Student drags an exit door icon. Red zones disappear as the exit approaches compliance. "You're at 43m. Maximum is 45m." Success when all areas are compliant.
SANDBOX
"This floor plan has been flagged by the Fire Marshal. Identify all travel distance violations and correct them by repositioning exits." Challenge Mode for advanced students.
BP 344 — Accessible Toilet + Ramp Configuration
Spatial Reasoning
BP 344's 2024 Revised IRR is one of the most dimension-dense codes in the ALE. Multiple clearances must coexist in one small space. Students fail these questions because they've never spatially resolved how all the dimensions fit together.
GUIDED
Top-down floor plan of a compliant accessible toilet. Sequential reveal: first, the 1.5m × 1.5m turning circle. Then, door swing clearance. Then, grab bar positions. Then, water closet centerline. A wheelchair icon navigates the space, showing whether each maneuver is achievable.
FADED
"The toilet is correctly positioned. Where does the grab bar go?" Drag-and-drop grab bar placement. Tolerance: ±50mm from correct position registers as correct. Incorrect placement shows the violation: "Grab bar must be 300mm from WC centerline — you placed it at 450mm."
SANDBOX
Ramp configurator: input slope percentage → model shows if gradient complies. Input landing length, width, handrail heights. Full ramp assembly renders at the set dimensions with compliance status visible.
History — Classical Orders Comparison
Visual Identity
Unlike code modules, this is purely visual identification training. Students confuse Doric and Tuscan, Ionic and Corinthian, because they've never seen them side by side with their distinguishing features annotated. The interaction pattern is fundamentally different from code compliance modules.
GUIDED
Five columns in a row. Scroll left-right to compare. Each order highlighted in sequence with its 3 identifying characteristics animated: "Doric: no base, plain capital, triglyphs in frieze." The animation highlights each feature as it's named. Subtle color coding per order (not code-compliance red/green — purely aesthetic differentiation).
IN-CANVAS
"Identify This Order" challenge — show a single column, student identifies it. Progressive difficulty: easy (very different orders), medium (Doric vs Tuscan), hard (blurred photo of real building column). Immediate feedback shows the distinguishing feature they should have looked at.
FADED
"Match the description to the order." Drag descriptions ("has scroll-like volutes on the capital") to the correct column. This builds verbal-to-visual and visual-to-verbal encoding simultaneously.
Section 06 · Anti-Patterns
Visual Learning UX Anti-Patterns to Avoid
Research-backed patterns that look good but harm learning. Specific to the 3D Lab context.
❌ Anti-Pattern 1 — Too Much at Once (Split-Attention Effect)
What it looks like: A structural bay model showing beams, columns, slabs, reinforcement details, connection types, and load paths simultaneously — all labeled, all visible.
Why it harms learning: Working memory overloads. The student looks at a complex model and understands nothing — their cognitive resources are spent just parsing the visual, not learning the content.
Fix: Progressive disclosure. Start with the skeleton frame only. Add one layer at a time. Let the student control the reveal. A "show layers" toggle is better than showing everything at once.
❌ Anti-Pattern 2 — Beautiful But Uninteractive
What it looks like: A photorealistic 3D render of a stairway that the student can orbit and zoom — but not modify.
Why it harms learning: Passive viewing of a 3D model produces little more retention than looking at a photograph. The learning comes from manipulation. A less-detailed model you can adjust is worth more than a photorealistic one you can only look at.
Fix: Prioritize interaction over visual fidelity. A simple parametric model with working sliders is more educationally valuable than a photo-realistic model with no controls.
❌ Anti-Pattern 3 — Model With No Exam Connection
What it looks like: A beautiful 3D model of a traditional Filipino bahay kubo — architecturally interesting, but with no direct connection to any ALE question type.
Why it harms learning: Students are motivated by exam relevance. Content that doesn't connect to a specific ALE question type reads as "interesting" but not as "study material." ALE candidates will not use content that doesn't directly serve their goal.
Fix: Every module must display "X ALE questions per sitting typically test this content" — and must link directly to Camp Mode quiz questions on the same topic.
❌ Anti-Pattern 4 — Labels That Replace Learning (Redundancy Effect)
What it looks like: A model where every single dimension is permanently labeled with its value.
Why it harms learning: The Redundancy Effect (Cognitive Load Theory) — when the labels provide all the answers, the student never has to retrieve the information themselves. The model becomes a reference, not a learning tool. Passive answer-display adds to cognitive load without adding to learning.
Fix: In guided mode, labels appear sequentially — not all at once. In quiz/sandbox mode, labels are hidden until the student has answered a question about that dimension. The model earns its labels through student engagement.
Section 07 · Philippine ALE Context
3D Lab Specifically for the Philippine ALE — What's Unique
The 3D Lab isn't for generic architecture education. It's specifically for passing the PRC Architecture Licensure Examination in the Philippines. That context creates specific requirements.
🇵🇭
Philippine Codes Only
Every dimension in the 3D Lab must reference a Philippine code specifically. Never use ANSI/ISO standards as default — only PD 1096, RA 9514, BP 344, NSCP 2015, PEC, National Plumbing Code. Foreign code references confuse students who then apply wrong values on the exam.
🏗️
Tropical Context Models
Philippine architecture has specific considerations: ventilation (ASHRAE vs PD 1096 natural ventilation requirements), typhoon-resistant design, hot-humid climate considerations. The 3D Lab should include models showing Philippine climate-responsive design — not just temperate-climate defaults.
📐
AMBF / PSO / TGFA Visualization
Filipino architecture students consistently struggle with PSO, AMBF, and TGFA calculations — these are uniquely Philippine metrics. A parametric site model where students practice these calculations with immediate visual feedback would fill a gap no existing ALE reviewer product currently addresses.
Unique SlateCamp Opportunity
No existing Philippine ALE prep platform offers interactive 3D visual learning. Arkitekto (the closest competitor) uses quizzes and spaced repetition — no visual learning layer. The 3D Lab is SlateCamp's most defensible competitive advantage and its most direct contribution to actual exam performance for Building Technology and Code subjects. The 186 modules planned cover content that is effectively impossible to understand through text alone. Build the top 10 first. Launch them. Track which modules correlate most strongly with improved Heatmap node states. Let the data tell you which to build next.
