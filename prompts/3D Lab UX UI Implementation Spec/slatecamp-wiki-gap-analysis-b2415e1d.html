03Schema Migration — 1 Required Column
Only one migration is needed. Add read_time_minutes to the wiki_articles table, then populate it for this article.
Migration: add read_time_minutes Run via Supabase apply_migration · name: add_wiki_read_time
Run first
Why: The WikiArticleHeader component needs read_time_minutes to render the "~18 min read" tag pill. Without it the tag row is missing one of its three elements.
Type: smallint — read times are always 1–60 minute integers.
Nullable: YES — existing articles without a read time set won't break. The frontend hides the read time tag pill when read_time_minutes is null.
Calculated how: Use the formula from the spec: total word count ÷ 125, rounded up to nearest integer. This article is ~6,000 words → ~48 minutes. Display shows "~18 min read" — so the stored value for this article should be 18 (matching what's in the article header tag).

04Component Naming Resolution — WikiCallout vs WikiCalloutBox
The content uses <WikiCalloutBox> (3 instances: version-alert, most-tested, ale-watch). The spec names the component <WikiCallout>. There are two valid solutions — pick one.
Option A — Name the React component WikiCalloutBox Zero content migrations · recommended
Recommended
Build the React component as WikiCalloutBox instead of WikiCallout
Export it as WikiCalloutBox from src/components/wiki/index.ts
Add to the MDX component map as WikiCalloutBox
No database changes needed. The existing content works immediately.
Update the spec document to use WikiCalloutBox as the canonical name
Option B — Migrate content to WikiCallout Keeps spec name · requires DB migration
Only if consistency with spec matters more
Run a SQL UPDATE that replaces all WikiCalloutBox with WikiCallout in content
Must be run on ALL wiki articles, not just this one
Build the React component as WikiCallout as originally specced
Higher risk — requires touching production content
-- Option B migration (only if chosen)
UPDATE wiki_articles
  SET content = replace(content,
    'WikiCalloutBox', 'WikiCallout')
  WHERE content LIKE '%WikiCalloutBox%';
Decision
Go with Option A. The content is correct. The spec document is a spec — it can be updated. Never run content migrations unless absolutely necessary. Name the React component WikiCalloutBox to match what's already in the database.

// src/components/wiki/WikiTable.tsx — full implementation
import { WikiChangedPill } from './WikiChangedPill'
import { cn } from '@/lib/utils'

interface WikiTableRow {
  parameter: string
  dimension?: string
  value: string
  source?: string
  isMostTested?: boolean
  isChanged?: boolean
  isSectionHeader?: boolean
}

interface WikiTableProps {
  caption?: string
  columns: string[]
  rows: WikiTableRow[]
  hasSourceColumn?: boolean
}

export function WikiTable({ caption, columns, rows, hasSourceColumn = true }: WikiTableProps) {
  return (
    <div className="my-6 rounded-lg border border-border overflow-hidden">
      {caption && (
        <p className="font-sans text-xs font-semibold text-ink px-3 py-2.5 border-b border-border bg-warm-white">
          {caption}
        </p>
      )}
      <div className="overflow-x-auto">
        <table className="w-full border-collapse">
          <thead>
            <tr className="bg-[#FAFAF8]">
              {columns.map((col, i) => (
                <th key={i} className={cn(
                  "font-mono text-[9px] font-medium uppercase tracking-widest text-ink-muted px-2.5 py-2 text-left border-b border-border",
                  i === columns.length - 1 && hasSourceColumn && "hidden sm:table-cell"
                )}>{col}</th>
              ))}
            </tr>
          </thead>
          <tbody>
            {rows.map((row, i) => {
              if (row.isSectionHeader) return (
                <tr key={i} className="bg-[#1B3FC414]">
                  <td colSpan={columns.length}
                      className="font-mono text-[9px] font-medium uppercase tracking-widest text-primary px-2.5 py-1.5">
                    {row.parameter}
                  </td>
                </tr>
              )
              return (
                <tr key={i} className={cn(
                  "border-b border-[#ECEAE4] last:border-b-0",
                  row.isMostTested && "bg-signal-gold-light"
                )}>
                  <td className="px-2.5 py-2.5 text-sm text-ink">
                    {row.parameter}
                    {row.isChanged && <WikiChangedPill className="ml-1.5" />}
                  </td>
                  {row.dimension && (
                    <td className="px-2.5 py-2.5 text-xs text-ink-muted">{row.dimension}</td>
                  )}
                  <td className={cn(
                    "px-2.5 py-2.5 text-sm font-semibold",
                    row.isMostTested ? "text-amber-800" : "text-primary"
                  )}>{row.value}</td>
                  {hasSourceColumn && (
                    <td className="px-2.5 py-2.5 font-mono text-[10px] text-ink-muted hidden sm:table-cell">
                      {row.source}
                    </td>
                  )}
                </tr>
              )
            })}
          </tbody>
        </table>
      </div>
    </div>
  )
}

import { createClient } from '@/lib/supabase/server'
import { MDXRemote } from 'next-mdx-remote/rsc'
import { notFound } from 'next/navigation'
import {
  WikiArticleHeader,
  WikiCalloutBox,   // NOTE: WikiCalloutBox, not WikiCallout
  WikiTable,
  WikiPartHeader,
  WikiChangedPill,
  WikiMistakeCard,
  WikiMistakeList,
} from '@/components/wiki'

// MDX component map — names must exactly match shortcodes in the DB content
const components = {
  WikiCalloutBox,   // matches <WikiCalloutBox type="..."> in content
  WikiTable,        // matches <WikiTable ...> in content (when converted)
  WikiPartHeader,   // matches <WikiPartHeader partNumber={N} ...> in content
  WikiChangedPill,  // matches <WikiChangedPill /> in content
  WikiMistakeCard,  // matches <WikiMistakeCard ...> in content (if used standalone)
  WikiMistakeList,  // matches <WikiMistakeList mistakes={[...]} /> in content
}

export default async function WikiArticlePage({
  params
}: {
  params: { slug: string }
}) {
  const supabase = createClient()

  const { data: article, error } = await supabase
    .from('wiki_articles')
    .select(`
      article_id,
      title,
      slug,
      content,
      status,
      subject_label,
      difficulty_label,
      ale_tests_you,
      updated_note,
      read_time_minutes
    `)
    .eq('slug', params.slug)
    .eq('status', 'published')
    .single()

  if (error || !article) notFound()

  return (
    <article className="wiki-prose max-w-3xl mx-auto px-4 sm:px-6 py-10">

      <WikiArticleHeader
        subject={article.subject_label ?? ''}
        difficulty={(article.difficulty_label ?? 'Intermediate') as any}
        readTime={article.read_time_minutes}
        title={article.title}
        updatedNote={article.updated_note ?? ''}
        aleTestsYou={article.ale_tests_you ?? ''}
      />

      <MDXRemote
        source={article.content}
        components={components}
      />

    </article>
  )
}

// Generate static params for all published articles
export async function generateStaticParams() {
  const supabase = createClient()
  const { data } = await supabase
    .from('wiki_articles')
    .select('slug')
    .eq('status', 'published')

  return (data ?? []).map((a) => ({ slug: a.slug }))
}
