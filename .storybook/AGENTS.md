# .storybook

## Scope

This file governs `.storybook/`.

## Responsibility

This subtree owns Storybook runtime configuration only.

## Edit rules

- Keep Storybook config aligned with the actual component/docs workflow.
- Do not treat Storybook validation as a substitute for app-wide validation.

## Anti-loop rule

- Audit artifacts do not recursively expand scope.
- Remediation requires a later implementation-approved run.
