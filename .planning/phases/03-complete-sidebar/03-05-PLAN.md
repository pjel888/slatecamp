**Step 2: Create SidebarShell -- the client wrapper with leave-session dialog.**

Create `src/components/sidebar/SidebarShell.tsx` as a 'use client' component.

This component handles the leave-session guard that was in the old Sidebar.tsx (lines 184-208, 424-455). It wraps SidebarRail + SidebarOverlay + Dialog.

Props:
```typescript
interface SidebarShellProps {
  isAdmin?: boolean
  isDevMode?: boolean
  userDisplay?: { name: string; avatarUrl: string | null }
  tier?: UserTier
}
```

Implementation:
- Uses `useActiveSession()` and `useRouter()` and `usePathname()` for the leave-session guard.
- State: `leaveDialogOpen`, `leaveTarget` (same as current Sidebar.tsx).
- `handleNavClick`: if activeSession and href !== pathname, preventDefault + show dialog.
- `handleConfirmLeave`: close dialog, navigate to target (with review exit special case).
- Renders `<SidebarRail>` passing isAdmin, onBeforeNavigate, userDisplay, tier, isDevMode.
- Renders `<SidebarOverlay>` passing isAdmin, onBeforeNavigate, userDisplay, tier, isDevMode.
- Renders the leave-session Dialog (copy the JSX from current Sidebar.tsx lines 424-455 exactly -- same classes, same text, same buttons).

The SidebarRail (in flex flow) and SidebarOverlay (position:fixed) are both children of SidebarShell. This works because SidebarShell is a fragment-like wrapper -- its children participate in the parent flex layout.

IMPORTANT: SidebarShell must render as a React fragment (`<>...</>`) so the SidebarRail participates directly in the flex layout of the parent div. If SidebarShell wraps in a div, the rail would be nested and flex layout would break.

**Step 3: Create SidebarContent -- thin client wrapper for contentRef.**

Create `src/components/sidebar/SidebarContent.tsx` as a 'use client' component.

```typescript
'use client'
import { useSidebar } from './SidebarProvider'

export const SidebarContent = ({ children }: { children: React.ReactNode }) => {
  const { contentRef } = useSidebar()
  return (
    <div ref={contentRef} className="flex flex-1 flex-col overflow-hidden border-l border-border">
      {children}
    </div>
  )
}
```

This is needed because layout.tsx is a server component and cannot use hooks. SidebarContent reads contentRef from context and applies the ref to the content wrapper div for inert management.
