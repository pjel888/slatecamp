```tsx

  <div className="absolute left-0 top-1/2 -translate-y-1/2 w-[3px] h-[14px] bg-primary rounded-r-full" />
)}
```

**Icon rendering:** Use SCIcon with the ICON_BOX wrapper. Weight 'bold' when active, 'regular' otherwise. Color text-primary when active, text-[#4A5568] otherwise.

**Variant behavior:**
- `rail`: Hide text with `sr-only` class (not opacity-0 which is current pattern -- sr-only is cleaner for the rail since text should not take space). Wrap the entire link in Tooltip with `side="right"` and `sideOffset={12}`. Tooltip className: `bg-[#1A2332] text-white font-medium text-xs`.
- `expanded`: Show text with normal `truncate whitespace-nowrap`. No tooltip. Show active indicator.

Use TransitionLink as the link element (import from @/components/shared/TransitionLink). Pass `onBeforeNavigate` through.
