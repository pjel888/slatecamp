# Session Reporting Standard

Every substantial Slatecamp session should end with a compact report.

## Implementation report

```text
Summary:
Files changed:
Verification:
Risks:
Next best action:
```

## Orientation report

```text
Executive summary:
Repository facts:
.ai findings:
Architecture map:
Conventions:
Risks:
AI-agent guidance:
Open questions:
```

## Debugging report

```text
Symptom:
Root cause:
Evidence:
Fix:
Verification:
Prevention:
```

## Design review report

```text
Overall judgment:
Hierarchy:
Interaction:
Visual system:
Accessibility:
Priority fixes:
```
