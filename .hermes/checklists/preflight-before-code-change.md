# Preflight Before Code Change

- [ ] Confirm user goal and success criteria.
- [ ] Check current Git status.
- [ ] Read relevant `.ai` notes if this is a Slatecamp orientation or architecture task.
- [ ] Inspect relevant files before editing.
- [ ] Identify repo-native package manager and commands.
- [ ] Identify tests or verification path.
- [ ] Note high-risk files or systems.
- [ ] Keep change scope narrow.
