# UI Quality Checklist

- [ ] Primary action is visually clear.
- [ ] Information hierarchy is obvious.
- [ ] Layout works on narrow and wide screens.
- [ ] Loading, empty, and error states exist.
- [ ] Spacing and type scale are consistent.
- [ ] Interactions have feedback.
- [ ] Accessibility basics are handled: labels, focus, contrast, keyboard path.
- [ ] Visual polish supports usability rather than decoration.
