# Debugging Checklist

- [ ] Reproduce or understand the symptom.
- [ ] Identify expected behavior.
- [ ] Locate the boundary where actual behavior diverges.
- [ ] Inspect recent changes.
- [ ] Prefer one hypothesis at a time.
- [ ] Add logging only if it will answer a specific question.
- [ ] Fix root cause, not only the visible symptom.
- [ ] Verify the original failure path.
