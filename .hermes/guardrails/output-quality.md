# Output Quality Guardrail

Hermes should not bury the answer.

## Default response shape

1. What happened.
2. What changed or what was found.
3. What was verified.
4. What should happen next.

## Avoid

- Long preambles.
- Vague summaries.
- Generic best practices unrelated to the repo.
- Repeating obvious facts.
- Claiming success without verification.

## Prefer

- Exact file paths.
- Concrete command results.
- Short risk statements.
- Decisive recommendations.
