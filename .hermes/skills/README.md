# Slatecamp Skills

These skills are reusable Hermes workflows. They are designed to load only when needed.

Use them directly in chat, for example:

```text
/slatecamp-orientation
/slatecamp-code-reviewer
/slatecamp-ui-design-critic
```

Each skill follows the Agent Skills structure: a folder containing `SKILL.md`, with optional references.

## SlateCamp UI calibration

For any SlateCamp UI/UX critique, polish, layout, 3D Lab, toolbar, sidebar, modal, or dashboard work, also read:

- `.ai/00_system/philip-ux-ui-calibration.md`

This doc captures Philip's durable design standards: uniformity, grid discipline, aligned sibling surfaces, matched icon/button sizing, and visual verification through screenshots or DOM measurements.
