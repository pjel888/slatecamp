# Indus Valley Civilization Architecture Refined Source Map

## Stable Source Anchors

- Indus/Harappan exam identity: Mohenjo-daro, Harappa, planned streets, standardized brick, wells, drains, citadel/lower town, and Great Bath.
- Urban planning and sanitation are the safest architecture claims.
- Social interpretation remains cautious because script, rulers, and religious meanings are not securely known.

## LEA Content Boundary

- High-yield items should ask about urban standardization, drainage, brick, Great Bath recognition, and source-safe uncertainty.
- Avoid deterministic collapse, exact acreage, and exact ritual-function claims.
