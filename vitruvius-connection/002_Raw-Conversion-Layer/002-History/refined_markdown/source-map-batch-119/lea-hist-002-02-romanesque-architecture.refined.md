# Romanesque Architecture Refined Source Map

## Stable Source Anchors

- Romanesque exam identity: semicircular arches, barrel vaults, groin vaults, massive piers, thick walls, small windows, fortress-like interiors, pilgrimage planning.
- Structural logic: barrel vaults create outward thrust, so walls thicken and openings shrink.
- Transitional logic: Durham and similar examples show experiments that help lead toward Gothic ribbed-vault and buttress systems.

## LEA Content Boundary

- Ask for Romanesque versus Gothic structural contrast.
- Avoid unsupported ranking claims about the biggest or first church unless a future capture supports them.
