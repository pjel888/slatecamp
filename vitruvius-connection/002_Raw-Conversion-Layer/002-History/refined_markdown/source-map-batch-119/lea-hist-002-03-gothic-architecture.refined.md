# Gothic Architecture Refined Source Map

## Stable Source Anchors

- Gothic exam identity: pointed arch, ribbed vault, flying buttress, skeletal support, clerestory, triforium, stained glass, verticality, and light.
- Structural logic: ribs gather loads, pointed arches adjust spans and thrust, flying buttresses transfer lateral thrust outside the wall.
- Recognition anchors: Chartres, Amiens, Reims, Cologne, Sainte-Chapelle.

## LEA Content Boundary

- Ask for the integrated system and source-safe building recognition.
- Avoid exact glass quantities, exact window counts, and disputed named-architect claims unless a new source capture supports them.
