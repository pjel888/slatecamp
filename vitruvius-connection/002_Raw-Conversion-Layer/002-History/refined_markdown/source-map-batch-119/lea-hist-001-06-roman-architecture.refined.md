# Roman Architecture Refined Source Map

## Stable Source Anchors

- Roman exam identity: arch, voussoir, keystone, barrel vault, groin vault, dome, oculus, amphitheatre cavea, opus caementicium, aqueduct.
- Pantheon: use as a source-safe anchor for a concrete domed rotunda with an oculus and unified interior space.
- Colosseum: use as a source-safe anchor for an elliptical amphitheatre with tiered seating, arched facade organization, and circulation for public spectacle.
- Pont du Gard: use as a source-safe anchor for Roman aqueduct infrastructure and monumental arch engineering.
- Material logic: Roman concrete and pozzolana enabled monolithic masses and vault/dome forms beyond strict Greek post-and-lintel temple composition.

## LEA Content Boundary

- High-yield questions may compare Roman arch-vault-dome systems with Greek trabeated systems.
- Avoid exact spectator counts, exact construction dates, and precise dimensions unless separately source-captured.
