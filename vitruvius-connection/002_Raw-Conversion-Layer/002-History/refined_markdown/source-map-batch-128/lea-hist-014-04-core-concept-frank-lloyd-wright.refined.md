# Refined Source Conversion: Frank Lloyd Wright

## Exam claim set

1. Frank Lloyd Wright is safely tied to organic architecture, open planning, inside-outside continuity, and site/material integration.
2. Prairie/Robie cues should be horizontal domestic composition, hearth/open plan, broad overhangs, and landscape relation.
3. Fallingwater should be tested through reinforced-concrete cantilevers and site integration over the waterfall.
4. Usonian questions should emphasize economical, compact middle-class domestic design.
5. Guggenheim questions should emphasize a continuous spiral ramp and circulation as spatial concept.

## Question edit policy

All linked questions should distinguish Wright's integrated organic logic from generic modernism, unsupported ornament prohibitions, and incomplete rationale fragments.
