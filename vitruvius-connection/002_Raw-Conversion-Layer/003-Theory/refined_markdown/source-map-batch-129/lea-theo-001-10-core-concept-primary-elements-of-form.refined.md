# Refined Source Conversion: Francis D.K. Ching: Primary Elements of Form

## Exam claim set

1. Primary elements are conceptual before they become visible architectural form.
2. A point marks position; a line is an extended point; a plane is an extended line; a volume is an extended plane.
3. Point, line, plane, and volume support exam classification, not style labeling or decoration.
4. A colonnade can be read as repeated point elements whose alignment creates a line.
5. Complex building analysis should identify organizing points, lines, planes, and volumes before choosing an answer.
