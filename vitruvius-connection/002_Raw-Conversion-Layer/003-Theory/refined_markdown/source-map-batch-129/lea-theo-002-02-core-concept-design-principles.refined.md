# Refined Source Conversion: Design Principles: Proportion, Balance, Rhythm, Contrast, Scale, and Character

## Exam claim set

1. Proportion relates parts to one another and to the whole; proportion systems include Golden Section, regulating lines, classical orders, Renaissance theories, Modulor, Ken, and anthropometry.
2. Scale must distinguish visual scale from human scale.
3. Contrast creates visual differentiation; rhythm comes from repeated or alternating formal elements.
4. Balance is equilibrium; symmetry is exact correspondence around a line, plane, center, or axis.
5. Design principles work together; do not answer as if one principle cancels the others.
