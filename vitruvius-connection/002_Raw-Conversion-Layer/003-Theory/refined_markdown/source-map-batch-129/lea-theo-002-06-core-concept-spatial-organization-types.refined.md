# Refined Source Conversion: Spatial Organization Types

## Exam claim set

1. Centralized organization groups secondary spaces around a dominant central space.
2. Linear organization arranges a series of spaces directly or through a separate linear space.
3. Radial organization combines a dominant central space with linear arms extending outward.
4. Clustered organization relates spaces by physical proximity and often shared function or visual trait.
5. Grid organization regulates forms and spaces by a three-dimensional grid pattern or field.
