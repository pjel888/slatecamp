# Refined Source Conversion: Architectural Elements and Articulation

## Exam claim set

1. Linear members can express movement, provide support for overhead planes, and form a three-dimensional frame.
2. Beams and girders span between supports and carry transverse loads.
3. Planes include overhead/roof/ceiling, wall, and base/floor/ground planes.
4. Articulation makes parts clear and can use material, color, texture, pattern, corners, openings, and light.
5. Openings can maintain wall continuity, mark entry, project, recess, provide shelter, or create transition.
