## Exam-Safe Synthesis
Biophilic design is pattern-based connection to nature. The checked source set supports visual and non-visual nature, thermal and airflow variability, water, dynamic light, and biomorphic forms, while local tropical references keep those patterns tied to shade, ventilation, humidity control, material culture, and maintenance.

## Real World Scenario
A school courtyard can use planting, shaded edges, filtered daylight, water only where maintenance and mosquitoes are controlled, and airflow variability. The result is biophilic because nature supports comfort and orientation, not because plants were added as decoration.
