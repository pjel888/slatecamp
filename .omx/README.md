# OMX Handoff Artifacts

This directory stores durable OMX planning, audit, and runtime handoff material that is useful across machines.

Tracked:
- `plans/`
- `context/`
- `reports/`
- `audit/`, excluding local environment inventory
- `logs/`
- `state/`
- `artifacts/`
- `tmp/`
- small runtime config and notepad files

Ignored locally:
- local environment inventory
- dirty worktree diff captures
