# OMX Handoff Artifacts

This directory stores durable OMX planning and audit handoff material that is useful across machines.

Tracked:
- `plans/`
- `context/`
- `reports/`
- `audit/`, excluding local environment inventory

Ignored locally:
- runtime logs and hook state
- screenshots and generated visual artifacts
- temporary scripts and scratch files
- local environment inventory
- machine-specific setup files
