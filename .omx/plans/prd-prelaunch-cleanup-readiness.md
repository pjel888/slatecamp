# PRD — Pre-launch Cleanup Readiness Analysis

## Acceptance Criteria
- Required `.ai/` planning docs exist and include required tables.
- Every documented page/API route has a recommended fate.
- Every documented feature has a recommended fate.
- Legacy/stale/stubbed/experimental candidates are listed with evidence and actions.
- Do-not-maintain list explicitly identifies behavior/code paths to stop preserving.
- Risk register and readiness scorecard exist.
- Audit log and known issues updated.
- Verification commands attempted/documented.
- No source-code deletion performed and no secrets exposed.
