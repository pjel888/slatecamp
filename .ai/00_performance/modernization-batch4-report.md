## Phase 2-3 — Analytics Client Caching

**Finding:** `getUser()` was already cached via `React.cache`. The real bottleneck was `createClient()` called independently by each of the 25+ analytics sections, creating 27+ SSR Supabase clients per page load — each calling `cookies()`.

**Fix:** Added `createCachedClient = cache(() => createClient())` in `shared-helpers.ts`. Updated all 16 analytics action files (the main `analytics.ts` + 15 sub-files) to import and use `createCachedClient` instead of `createClient` from `@/lib/supabase/server`.

**Files changed:** 16
- `src/lib/actions/analytics/shared-helpers.ts` — added `createCachedClient`
- `src/lib/actions/analytics.ts` — replaced 7 createClient() calls
- `src/lib/actions/analytics-data.ts` — replaced 5 createClient() calls
- 13 sub-files in `src/lib/actions/analytics/` — replaced 17 createClient() calls

**Estimated impact:** ~27 SSR client creations → 1 per analytics page load. `React.cache` deduplicates within a single request boundary.

## Phase 6 — SettingsCard Evaluation

**Finding:** 7 settings cards share the same header structure (icon + title + description in `bg-muted/50 border-b`). However, each card has unique content bodies that vary significantly (form fields, toggles, profile editors, notification lists). Extracting just the header would create a thin wrapper that adds indirection without meaningful simplification.

**Decision:** Deferred to Batch 5. A better approach may be a `SettingsPage` layout component that standardizes the full page structure (list + card body) rather than extracting just the header.

## Phase 7 — Pricing Font Instantiation

**Finding:** `Instrument_Serif` Google Font is instantiated in 3 separate files:
- `pricing-content.tsx`
- `PricingCard.tsx`
- `MarketingFooter.tsx`

Each calls `Instrument_Serif({ subsets: ['latin'], weight: '400' })` independently. The font configuration is identical.

**Fix candidate:** Extract into one shared font export in a centralized location. Low risk, 3 files changed, no visual impact.

**Decision:** Deferred to Batch 5 — trivially safe but needs verification that the shared export pattern matches existing Next.js font conventions.
