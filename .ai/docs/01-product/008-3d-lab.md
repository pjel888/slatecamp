# 3D Lab

**Analysis Date:** 2026-04-06

## Overview

The 3D Lab provides spatial visualization for ALE preparation using React Three Fiber (R3F) and Three.js. Students interact with building models, annotate hotspots, explore compliance scenarios, and study spatial relationships in an immersive 3D environment.

**Source:** `src/features/3d-lab/`, `src/app/dashboard/3d-lab/`, `src/components/3d/`, `src/components/3d-lab/`

## Target Performance

- **60 FPS** target for smooth interaction
- **dpr: [1, 1.5]** for retina display optimization
- **frameloop: "demand"** — only re-renders when state changes

## Module System

3D learning modules are pre-built scenes targeting specific ALE topics:

| Module Category | Examples |
|-----------------|----------|
| Building Laws | Setback visualization, height limits, lot occupancy |
| Structural Design | Beam-column connections, foundation types, load paths |
| Fire & Life Safety | Egress routes, fire separation, sprinkler placement |
| MEPF Utilities | HVAC routing, electrical panel placement, plumbing risers |

## Compliance Check

Built-in Philippine Building Code (PD 1096) calculations:

| Rule | Computation |
|------|-------------|
| **AMBF** | Allowable Maximum Building Floor Area |
| **PSO** | Parking Space Obligation |
| **TGFA** | Total Gross Floor Area |
| **ISA** | Interior Space Allocation |
| **USA** | Usable Space Area |
| **TOSL** | Total Open Space Required |
| **MACA** | Maximum Allowable Construction Area |
| **FLAR** | Floor Area Ratio |
| **BHL** | Building Height Limit |
| **GFA** | Gross Floor Area |
