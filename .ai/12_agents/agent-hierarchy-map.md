# Agent Hierarchy Map

**Last Updated:** 2026-04-16

## Levels
- **Level 1:** root `AGENTS.md`
- **Level 2:** subtree governors like `.ai/AGENTS.md`, `src/AGENTS.md`, `supabase/AGENTS.md`
- **Level 3+:** route/domain-specific AGENTS under `src/app/*`, `src/components/*`, `src/lib/*`, etc.

## Update discipline
Any AGENTS refresh should be verified from root down to the touched subtree, not inferred from folder names.
