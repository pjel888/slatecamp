# Barangay Halls: Civic Use, Assembly Triggers, and Mixed Occupancy

## Source Scope

This local repair is limited to PD 1096 occupancy classification, the RA 9514 2019 Revised IRR, and the local Fire Code source family. Earlier population-threshold, office-area, counter-layout, and BP 344 statements are not carried forward because those source families were outside this Batch 064 raw-PDF audit.

## LEA Anchor

A barangay hall question usually tests source selection. The building may be a civic or government center, a community center, a multi-purpose barangay hall in a residential matrix context, an assembly space, or a mixed-use facility depending on the actual rooms and occupant load.

## PD 1096 Classification

PD 1096 lists Multi-purpose/Barangay Hall in the checked residential matrix context. It also lists civic centers, community centers, civic or government centers, and other government buildings in the checked Group C matrix. Because the same public building can be described by several rows, the prompt must state which table or use controls.

## RA 9514 Assembly and Mixed Use

RA 9514 treats gathering spaces for 50 or more persons for deliberation, worship, entertainment, eating, drinking, amusement, waiting, or similar uses as assembly occupancies. If a small assembly room is incidental to another occupancy and serves fewer than 50 persons, it is classified with the other occupancy. In mixed occupancy, egress and safeguards must satisfy the relevant occupancy requirements and the most stringent safeguards involved.

## Exam Use

For barangay halls, classify the office/civic use first, then separately test the session hall, event hall, day-care room, clinic, or public waiting area. Do not assume a single barangay-hall label answers every PD 1096 or RA 9514 question.
