Tropical green building in the Philippines joins climate-responsive design with documented code and rating concerns. The Green Building Code scope includes resource and environmental performance areas, while BERDE provides assessment categories; neither source supports treating certification, code compliance, and tropical expression as interchangeable.

## Board Exam Quick Check
Separate tropical climate response, Green Building Code compliance, and voluntary rating documentation; do not claim certification from a design strategy alone.

## Core Concept
Green building practice should be evidence-led: reduce environmental loads through climate-responsive architecture, then document water, energy, site, material, indoor-environment, and waste decisions against the applicable local code and rating framework.

## Real World Scenario
For a mid-rise office in Metro Manila, green design should begin with tropical load reduction: shade, ventilation where appropriate, envelope control, water efficiency, and indoor environmental quality. Documentation can then map those decisions to the Green Building Code scope and, if pursued, to BERDE categories.

## Key Facts
- The Philippine Green Building Code source identifies water, energy, renewable energy, sustainable materials, site, and indoor environmental quality concerns.
- BERDE documentation lists assessment categories including management, land use and ecology, water, energy, transportation, IEQ, materials, emissions, and waste.
- Code compliance, green rating assessment, and climate-responsive design are related but distinct.
- Tropical green design should reduce cooling load before depending on equipment or labels.
- Unsupported exact thresholds and point claims must be checked against the governing document before exam use.

## Common Mistakes
