## Board Exam Quick Check

For mixed-use questions, first classify the uses. Do not jump to podium-tower formulas, FAR values, or acoustic claims unless the item gives a source for them. The source-safe local baseline is PD 1096 RIRR occupancy classification and change-of-use control.

## What You Need to Know for the LEA

Mixed-use programming combines more than one use or occupancy in one building or development. In this batch, the safe source-audited treatment is not a generic real-estate typology lesson. It is a code-and-programming task: identify the use or occupancy, check whether uses are principal, accessory, or conditional, and determine whether the proposed or changed use conforms to the Code and IRR.

PD 1096 RIRR states that buildings proposed for construction are identified according to use or character of occupancy. It lists 10 groups of occupancies subdivided into 25 divisions and includes a schedule of principal, accessory, and conditional uses or occupancies. It also states that a building with a Certificate of Occupancy may receive other certificates due to changes in use, provided the new use conforms with the Code and IRR.

## Learning Goal

- Treat mixed-use as a classification and programming problem before treating it as a form problem.
- Identify principal, accessory, and conditional use cues.
- Recognize that changes in use require source-controlled conformance checks.

## Core Concept

A mixed-use item normally gives you a combination of uses: residential, business, mercantile, assembly, institutional, storage, accessory, or other categories. Under PD 1096 RIRR, the first exam move is to classify each use or character of occupancy.

After classification, programming checks relationships and conflicts. The Design Process source supports this by requiring existing-state analysis, future-state goals, performance requirements, and translation guidelines. RA 9266 IRR supports building programming, site analysis, and planning or utilization of spaces as part of architectural practice.

Do not assume that mixed-use automatically means a podium-tower, shared lobby, specific FAR, or a fixed parking formula. Those may be design or zoning issues in a given problem, but they are not source-safe unless the item gives the rule.

## Key Facts and Testable Items

| Exam cue | Source-safe answer |
| --- | --- |
| Multiple uses in one project | Classify each use or occupancy first. |
| Principal/accessory/conditional language | Use the PD 1096 RIRR schedule. |
| Change in use after occupancy | Check the Certificate of Occupancy/change-of-use rule and conformance with Code and IRR. |
| Program conflict | Resolve by documenting requirements, constraints, and translation guidelines. |
| RA 9266 IRR | Building programming and space planning are within architectural practice. |

## How It's Tested on the LEA

Expect questions that ask for the correct planning sequence. The safe answer usually starts with classification and source checking, not with form. If the item describes a residential-commercial combination, identify applicable occupancies, then check if accessory or conditional uses and change-of-use controls apply.

## Common Mistakes

- Assuming all mixed-use questions are about podium-tower form.
- Ignoring occupancy classification and use conformance.
- Treating accessory use as automatically allowed without checking conditions.
- Quoting FAR or acoustic numbers not present in the source.

## Key Terms

**Mixed-Use Programming** - Planning more than one use or occupancy in a source-controlled way.

**Use or Occupancy Classification** - PD 1096 RIRR identification of buildings according to use or character of occupancy.

**Principal Use** - A primary use listed in the checked occupancy schedule.

**Accessory Use** - A use incidental to the principal use, subject to source conditions.

**Conditional Use** - A use allowed only when stated conditions or approvals are satisfied.
