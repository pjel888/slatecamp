## Source-Safe Scope

Batch 137 grounds bubble diagrams in checked local sources: program lists, space descriptions, interrelationship matrix, bubble diagram, adjacency, concept diagrams, and basic spatial relationships.

This Batch 137 rewrite is intentionally narrower than the residual article when the residual claims exceeded the local source layer. The rewrite excludes hospital-specific, acoustic, security, and code adjacency rules unless separately sourced. It treats bubble diagrams as abstract relationship tools, not dimensioned plans.

## Core Concept

Use bubble diagrams to reason about relationships: adjacency, separation, hierarchy, linking spaces, and circulation before fixing dimensions.

Use the concept as an exam reasoning tool, not as a loose style label. The safest answer starts from the checked local source boundary, identifies the project information the source actually supports, and refuses unsupported exact values, awards, legal rules, global-market statements, or technology claims.

## Real World Scenario

A barangay learning center must link reading, tutoring, staff, storage, toilets, and outdoor waiting. A source-safe bubble diagram tests which spaces need adjacency, separation, or a common linking space before the design becomes a scaled plan.

## Exam Use
