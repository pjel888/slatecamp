# Stair Design: Source-Safe Code Framing

## Source Scope

This local-first revision removes unsupported ergonomic formulas and non-audited accessibility dimensions. The article is limited to checked PD 1096 stair/egress provisions, BP 344 2024 accessibility provisions, RA 9514 egress provisions, and Fire Code life-safety framing.

## LEA Anchor

A stair question is source-safe when it asks which checked rule controls: occupant-load width, rise and run, landings, handrails, headroom, roof access, enclosure, tactile warning, or accessible vertical route.

## PD 1096 Stair Controls

PD 1096 states minimum stair widths by occupant load, maximum riser and minimum run, landing dimensions, maximum vertical distance between landings, handrail height, stair-to-roof requirement, required stairway headroom, and enclosure conditions for interior stairways, ramps, or escalators.

## Accessibility Controls

BP 344 2024 requires handrails on both sides of ramps and stairs, states the accessible handrail heights, requires handrail extensions, and includes tactile paths and warning tactile blocks for accessible staircases. For persons with disabilities, BP 344 2024 identifies elevators as the preferred means of vertical access in the checked tactile-path provision.

## Exam Use

Do not treat a comfort formula as the code answer when the prompt asks for compliance. Start with the source named by the item, then apply the checked dimensional or accessibility requirement.
