# Resorts and Eco-Tourism Facilities: Source-Safe Code Framing

## Source Scope

This local-first revision limits the article to checked PD 1096, RA 9514, and Fire Code source-family evidence. It does not add unsupported eco-tourism planning rules, BP 344 dimensions, hotel star ratings, or generic travel-distance formulas that were not within the selected raw-source gate.

## LEA Anchor

A resort is usually a collection of functions, not a single automatic code answer. Classify each component before applying fire-safety requirements.

## Occupancy Classification

PD 1096 includes recreational uses in several places. The checked matrix lists recreational facilities such as resorts, swimming pools, and clubhouses as conditional uses in the A-2 row, and lists all types of resort complexes under Division H-4 for recreational tourism-oriented establishments. It also lists resort areas and beaches with accessory uses in the Group I assembly context for very large assembly conditions.

RA 9514 does not make every resort space the same occupancy. Restaurants and drinking establishments with fifty or more persons are assembly occupancies, while those below fifty persons are mercantile. Sleeping accommodation may trigger residential or hotel/dormitory provisions depending on the actual use. Mixed occupancies require egress sufficient for each individual room or section and safeguards meeting the most stringent occupancy requirements involved.

## Fire and Life Safety Checks

The Fire Code source family requires exits of the kind, number, location, and capacity appropriate to occupancy character, occupant count, fire protection, height, and construction type. For resort work, the checked source-safe posture is to classify dining, lodging, recreation, and support/storage areas separately before choosing the controlling exit, alarm, lighting, and protection rules.

## Exam Use

If an item says eco-tourism resort, avoid inventing an eco-tourism code category. Source-safe analysis asks what the component actually is: resort complex, dining assembly, small mercantile restaurant, sleeping accommodation, storage, or mixed occupancy.
