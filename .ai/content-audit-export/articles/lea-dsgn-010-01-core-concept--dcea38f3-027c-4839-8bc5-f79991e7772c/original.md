## Learning Goal
Calculate minimum parking requirements per occupancy type using NBC ratios, identify accessible and compact space allocations, apply parking ratios per PD 1096 (e.g., 1 slot/room for de luxe hotels), and verify compliance for mixed-use projects.

Parking requirements determine the minimum number of vehicle spaces a building must provide based on occupancy type and size.

## Core Concept

Parking demand scales with building use. The National Building Code (NBC) prescribes minimum ratios—expressed as spaces per unit, per square meter of floor area, or per occupancy measure—that reflect typical peak demand. These ratios balance operational feasibility against public policy, such as reducing on-street parking pressure.

A proposed building contains:

- **Office space:** 800 m² GFA
- **Restaurant (dining area):** 200 m² of dining space

**Step 1: Apply NBC Ratios (PD 1096 Rule XIX, Section 1903)**

- **Office:** 800 m² ÷ 125 m²/slot = **6.4 → 7 slots**
- **Restaurant dining:** 200 m² ÷ 30 m²/slot = **6.67 → 7 slots**
- **Subtotal = 14 slots**

**Step 2: Add Accessible Parking (BP 344 & Rule XIX)**

- 1% of 14 = 0.14 → **Minimum 2 slots required** (Always round up to at least 2 for any building requiring accessible parking).
- **Accessible total = 2 slots**.

**Step 3: Breakdown by Type**

- **Standard spaces:** 11 slots (2.5m × 5.0m).
- **Compact spaces:** Max 3 slots (2.4m × 4.8m). Note: Rule XIX allows up to 25% of total slots to be compact.
- **Accessible spaces:** 2 slots (3.7m × 5.0m per Rule XIX; often designed as 4.0m width for better BP 344 compliance).

## Key Provisions: NBC Parking Ratios (Rule XIX)

| Building Use | Unit of Measurement | Ratio (Minimum) |
|:---------------------------- |:-------------------- |:----------------- |
| **Residential** | | |
| Single-family dwelling | Per dwelling unit | 1 space |
| Apartment (10+ units) | Per unit | 1 space |
| Condominium | Per unit | 1 space |
| Boarding house | Per 4 beds | 1 space |
| **Commercial** | | |
| Office | Per 125 m² GFA | 1 space |
| Retail / Mall | Per 100 m² GFA | 1 space |
| **Food & Beverage** | | |
| Restaurant/dining | Per 30 m² dining area | 1 space |
| **Hospitality/Institutional** | | |
| Hotel | Per 10 guest rooms | 1 space |
| Hospital | Per 25 beds | 1 space |
| School (Elem/Sec) | Per 10 classrooms | 1 space |
| Theater / Assembly | Per 50 seats | 1 space |
| **Industrial** | | |
| Warehouse | Per 1,000 m² GFA | 1 space |

### Parking Space Dimensions (PD 1096 Rule XIX, Sec. 1905)

| Stall Type | Width | Length | Notes |
|:--------------- |:----- |:----- |:------------------------------------------- |
| **Standard car** | 2.5 m | 5.0 m | Primary stall type |
| **Compact car** | 2.4 m | 4.8 m | Maximum 25% of total slots |
| **Truck/Bus** | 3.6 m | 12.0 m | For loading/unloading |
| **Motorcycle** | 0.75 m | 2.25 m | Optional provision |
| **Accessible** | 3.7 m | 5.0 m | Minimum 1% of total, min 2 slots |

_Note: While Rule XIX specifies 3.7m width for accessible stalls, BP 344 design standards often suggest a 1.2m wide access aisle adjacent to a standard stall, effectively creating a 3.7m to 4.0m width._

## Calculation Protocol

1. **Identify all occupancy types** in the project.
2. **Measure relevant area** for each type (GFA for office/retail, dining m² for restaurants, bed/room counts).
3. **Apply NBC Rule XIX ratios**.
4. **Sum required spaces** and round up fractions.
5. **Add 1% Accessible slots** (always minimum 2).
6. **Determine Compact allocation** (Max 25% of total).

## How It's Tested

**Pattern 1: The Office/Retail Summation**
Scenario: 2,500 m² Office + 500 m² Retail.

- Office: $2,500 / 125 = 20$ slots.
- Retail: $500 / 100 = 5$ slots.
- Total: 25 slots + 2 accessible = 27 slots.

**Pattern 2: The Accessible Minimum**
An office building requires only 48 slots by GFA. How many accessible spaces are needed?

- Answer: **2 slots**. Even though 1% of 48 is 0.48, the law mandates a minimum of 2.

**Exam Tip — ERR-DSGN-013:** Parking minimums are per PD 1096 Rule XVIII and local zoning ordinances, not the same nationwide. Accessible stalls must be provided at a minimum of 1 per 50 standard stalls (BP 344).
