## What You Need to Know for the LEA

## Learning Goal

Apply Revised National Plumbing Code fixture unit values to calculate drainage fixture unit (DFU) loads, size horizontal branches and vertical stacks, and determine minimum pipe diameters for sanitary drainage systems.

<ExamTip>
LEA plumbing questions often give a fixture schedule and ask for the minimum pipe diameter. Memorize common DFU values: water closet = 4–6 DFU, lavatory = 1–2 DFU, shower = 2–3 DFU, kitchen sink = 2 DFU. Sum the DFUs and use the code table to select the pipe size.
</ExamTip>

<Tip>
A quick memory aid for horizontal branch sizing: 1 DFU ≈ 1 fixture unit, and the Revised National Plumbing Code provides a direct lookup table. For a stack, remember that the vertical stack can handle more DFUs than a horizontal branch of the same diameter because gravity assists flow.
</Tip>

<Warn>
Do not confuse DFU with water supply fixture units (WSFU). The LEA may present both in the same question. DFU is for drainage; WSFU is for water supply. They use different tables and cannot be interchanged.
</Warn>
