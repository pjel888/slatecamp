# Architectural Drawing Communication

## Board Exam Quick Check

For symbol and notation questions, ask what the drawing must communicate to the builder, reviewer, or Building Official. Use the legend, schedule, section cut, detail marker, dimension, and code note before guessing from a symbol alone.

## What You Need to Know for the LEA

PD 1096 requires building plans and construction drawings to communicate the project at a usable scale. In the checked source, floor plans show gridlines and complete identification of rooms or functional spaces. Elevations show gridlines, ground-to-finish-grade elevations, floor-to-floor heights, door and window marks, material type, exterior finishes, and adjoining existing structures where applicable. Sections show cut and visible parts, levels, doors and windows with direction of opening, partitions, cabinets, and the rooms or spaces cut by the section line.

The same source requires schedules of doors and windows showing types, designations or marks, dimensions, materials, and number of sets. A symbol is therefore only useful when it is coordinated with the legend, notes, schedules, and specifications.

Source-safe drawing interpretation:

| Drawing item | What it communicates |
| --- | --- |
| Door arc | Swing direction and leaf path in plan |
| Window tag | A window type that must match the window schedule |
| Stair note such as 12R | Number of risers, not number of storeys |
| Section cut with arrows | Cut location and viewing direction |
| Detail marker | Where to find a larger-scale detail |
| Material hatch | A convention that must be confirmed by legend or specification |
| Fire-rating note | A required performance note to coordinate with code and specifications |

Accessibility symbols and dimensions should be coordinated with the accessibility drawings. In the checked local accessibility text, accessible elevators have a minimum dimension of 1.10 m x 1.40 m, ramps have a maximum gradient of 1:12, accessible doors have a minimum clear width of 0.80 m, and accessible parking slots have a minimum width of 3.70 m.

## How It Is Tested

- Interpret door, window, stair, section, and detail symbols by their drawing role.
- Use schedules and legends to confirm what a tag or hatch means.
- Do not invent a code section number for a drawing convention.
- Distinguish an elevator requirement from an accessible elevator cab dimension.
- Treat missing legends and undefined symbols as coordination errors.

## Common Mistakes

- Reading 12R as twelve storeys instead of twelve risers.
- Treating material hatches as universal legal symbols without checking the legend.
- Missing the viewing direction shown by section arrows.
- Using an accessibility dimension without checking the project condition.
- Letting a symbol conflict with the door/window schedule or detail reference.
