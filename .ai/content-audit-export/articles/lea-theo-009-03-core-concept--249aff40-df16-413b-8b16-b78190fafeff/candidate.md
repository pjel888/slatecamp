## Board Exam Quick Check

For space-standard questions, do not answer from memory unless the item names the controlling source. Identify whether the question is asking for PD 1096 minimum code control, accessibility dimensions, program requirements, or a design preference.

## What You Need to Know for the LEA

PD 1096 RIRR provides the safe local baseline for code-related space questions in this batch. It declares a framework of minimum standards regulating building location, site, design, use, occupancy, and maintenance. It also requires buildings and accessory facilities to be suited to their intended purpose.

The same IRR treats inadequate room sizes, space dimensions, and window openings as architectural deficiencies in the dangerous or ruinous building context. It also requires architectural floor plans and sections to identify rooms and functional spaces, which means space planning must be documented clearly.

## Learning Goal

- Distinguish code minimums, accessibility requirements, and design-preference claims.
- Anchor space-standard answers to the named controlling source.
- Avoid unsupported memorized room dimensions when the local source does not state them.

## Core Concept

A source-safe space-standard answer begins with the controlling rule. PD 1096 RIRR classifies building use and occupancy into groups and divisions, regulates design and occupancy, and requires plans to show rooms and functional spaces. For accessibility, the RIRR includes design data such as wheelchair dimensions, reach ranges, and wheelchair turning spaces.

The Design Process source also supports the programming side of space standards: performance requirements and translation guidelines convert goals into more specific spatial requirements. A space standard is therefore not just a number. It must respond to use, occupancy, accessibility, safety, and documented program requirements.

## Key Facts and Testable Items

| Exam cue | Source-safe answer |
| --- | --- |
| PD 1096 RIRR policy | Minimum standards for location, site, design, use, occupancy, and maintenance. |
| General building requirement | Buildings and accessory facilities must be suited to intended purpose. |
| Dangerous/ruinous building clue | Inadequate room sizes, space dimensions, and window openings are architectural deficiencies. |
| Plan documentation | Floor plans and sections identify rooms and functional spaces. |
| Accessibility clue | Wheelchair dimensions and 1.50 m turning guidance are accessibility planning data in the IRR. |
| Programming clue | Performance requirements can become translation guidelines. |

## How It's Tested on the LEA

Expect questions that try to make you choose an unsupported room-size rule. If the item names PD 1096, use PD 1096. If it names accessibility, use the accessibility provisions. If it gives a design brief without a legal source, treat the dimensions as programming requirements that must be documented and tested.

## Common Mistakes

- Treating a handbook dimension as if it were automatically PD 1096.
- Ignoring occupancy classification before applying a space rule.
- Forgetting that inadequate room sizes and space dimensions can be code-relevant defects.
- Omitting room and functional-space identification from plans.

## Key Terms

**Space Standard** - A minimum or required spatial control tied to a source, use, occupancy, accessibility need, or program requirement.

**Occupancy Classification** - PD 1096 RIRR grouping of building uses that affects applicable requirements.

**Architectural Deficiency** - A code-relevant defect such as inadequate room size, space dimension, or window opening in the checked IRR context.

**Translation Guideline** - A program-derived spatial or performance requirement used to guide design decisions.
