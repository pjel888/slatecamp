# Site development planning

## What You Need to Know for the LEA

## Learning Goal
Prepare and evaluate a site development plan by coordinating lot boundaries, orientation, proposed and existing structures, access, driveways, utilities, easements, rights-of-way, setbacks, benchmarks, adjacent streets, and drainage/site constraints.

PD 1096 lists the site development plan as an architectural document. It should show technical description, boundaries, orientation, and the position of the proposed building or structure in relation to the lot, existing or proposed access roads and driveways, and existing public utilities or services. Existing buildings within and adjoining the lot must be shown, and distances between proposed and existing buildings indicated.

The checked construction source reinforces the site-plan checklist. A site plan should identify legal description, source and date of land survey, property-line dimensions and bearings, project limits, north arrow and scale, benchmarks for location and elevation of new work, adjacent streets and rights-of-way, easements or rights-of-way crossing the site, and setbacks required by zoning.

This batch does not use unchecked PD 957, PD 1067, BP 220, or local zoning numeric formulas for site development calculations. If a question provides a setback, PSO, FLAR, easement, or open-space value, you may calculate from the given data. If it does not provide the controlling source, do not invent one.

| Site development item | Source-safe check |
| --- | --- |
| Lot and survey data | Boundaries, bearings, north arrow, scale, benchmarks, and legal description. |
| Building placement | Proposed structure position relative to the lot and existing/adjoining structures. |
| Access | Existing or proposed access roads, driveways, adjacent streets, and rights-of-way. |
| Utilities | Existing public utilities and services that affect layout and service routes. |
| Easements and setbacks | Show and respect the controlling easements, rights-of-way, and setback data supplied by the source or problem. |

## Key Takeaways

A site development plan coordinates the building with the lot, access, utilities, existing structures, and legal/site constraints.

Compute only from values supplied by the problem or checked source packet.

When an item mixes zoning, easement, utility, and open-space numbers, first identify which value controls which area before calculating.
