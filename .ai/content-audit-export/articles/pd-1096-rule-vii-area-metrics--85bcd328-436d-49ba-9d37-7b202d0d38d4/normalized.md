# PD 1096 Rule VII: Area Metrics and Building Bulk

## LEA Point

Rule VII area problems are not solved by one percentage. Work in layers:

1. Identify the use or occupancy and lot condition.
2. Use Rule VIII to establish the allowable ground coverage and open-space frame.
3. Use Rule VII to test building height, allowable maximum total gross floor area, and allowable maximum volume.
4. Apply any local zoning or other stricter development control.

The exam trap is mixing the terms. PSO controls the occupied portion of the lot at grade. FLAR is a building-bulk guideline for GFA. TGFA is broader than GFA because it includes enclosed support areas and other usable horizontal surfaces. AMVB is the volume crosscheck.

## Source Anchors

- Rule VIII Table VIII.1 is the basic open-space table. It gives PSO, ISA, USA, and TOSL relationships by use or occupancy.
- Rule VIII Table VIII.1 notes that PSO plus ISA equals MACA, and PSO plus TOSL equals TLA.
- Rule VII Section 705 and Table VII.1 express allowable maximum TGFA as BHL multiplied by the allowable maximum building footprint percentage of TLA, with reduction when needed to satisfy AMVB.
- The Rule VII building-bulk guideline identifies FLAR as the primary or initial determinant of building bulk.
- The same guideline defines GFA as floor space within permanent external building walls, including corridors, lobbies, mezzanines, and floor-like projections such as certain balconies.
- The GFA exclusions in the guideline include covered parking and driveways, services and utilities, vertical penetrations in parking floors without units, and specified uncovered roof or amenity areas.
- TGFA includes GFA plus non-GFA areas, then excludes courts above grade required under Rule VIII.
- Rule VII Section 706 permits floor-area increases only in specific instances based on public space, streets, or yards along and adjoining two or more sides of the building, subject to Building Official approval.

## Computation Order

Start with the lot.

Use TLA as the total lot area. Apply setbacks, courts, yards, and permitted firewall conditions to determine the allowable maximum building footprint. Then check that footprint against the PSO in Rule VIII Table VIII.1.

Next, test height. Use the applicable BHL from Rule VII Table VII.2 and any stricter RROW, zoning, airport, or site condition. Height is not a reward for using less ground coverage; it is separately controlled.

Then compute area and volume. The Rule VII table form is:

Allowable maximum TGFA = BHL x allowed AMBF percentage of TLA.

The guideline also requires AMVB checking. A scheme that fits the TGFA figure can still fail if the building bulk or angular-plane limits reduce the allowable volume.

## GFA, TGFA, and FLAR

GFA and TGFA are not synonyms.

GFA is tied to the building floor space within permanent external walls. It includes main occupiable areas, corridors, lobbies, mezzanines, and floor-like projections that are directly integrated into the building.

TGFA is broader. It starts from GFA, adds non-GFA areas and other usable horizontal surfaces above or below grade, and then deducts courts required above grade under Rule VIII.

FLAR is a guideline ratio used to estimate building bulk:

GFA = TLA x recommended FLAR.

Use FLAR for the GFA/bulk check. Use Table VII.1 and BHL for the allowable maximum TGFA check. Do not substitute one for the other unless the problem statement explicitly tells you which control is being tested.

## Floor-Area Increase Trap

Section 706 does not say that a building earns extra floor area merely because it is a corner lot or because sprinklers are present. The source condition is more specific: public space, streets, or yards must extend along and adjoin two or more sides of the building or structure, and the increase remains subject to Building Official approval.

## Exam Workflow

1. Name the occupancy and lot condition.
2. Pull the PSO/open-space rule from Rule VIII Table VIII.1.
3. Establish AMBF and check PSO against TLA.
4. Pull the BHL from Rule VII Table VII.2 and stricter local/RROW/site controls.
5. Compute GFA using FLAR only when the problem asks for the guideline building-bulk check.
6. Compute TGFA using Rule VII Table VII.1.
7. Crosscheck AMVB and angular-plane limits where the problem gives height or RROW facts.
8. Apply Section 706 only when the two-or-more-sides public-space condition and Building Official approval are present.

## Board-Style Memory

PSO is footprint. FLAR is GFA/bulk. TGFA is the broader total gross floor area test. AMVB is the volume crosscheck. A compliant answer keeps those four controls separate.
