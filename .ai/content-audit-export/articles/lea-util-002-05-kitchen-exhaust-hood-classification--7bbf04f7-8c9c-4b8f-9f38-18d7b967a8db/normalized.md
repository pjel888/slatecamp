# Kitchen exhaust hood classification

Kitchen exhaust questions should be answered from the checked local kitchen-ventilation and fire-protection source families. For this batch, the primary local sources are the DOE Energy Conserving Design Guidelines, George Salvan's Architectural Utilities 2, and the RA 9514 Revised IRR.

## Exam Anchor

Start by deciding whether the item asks about hood exhaust flow, ducted versus ductless equipment, or fire-protection requirements for cooking equipment. These are related, but they are not the same answer path.

## What The Checked Sources Support

The DOE guidelines include basic hood styles for Type 1 kitchen applications. The listed styles include wall-mounted canopy, single-island canopy, double-island canopy, eyebrow, and back-shelf or pass-over hoods. The DOE table gives typical model-code exhaust flow relationships for conventional Type 1 hoods. In that table, Q is the exhaust flow rate in cubic meters per second, and A is the hood exhaust aperture area in square meters. The table uses formulas such as Q = 0.5A for wall-mounted canopy hoods and Q = 0.75A for single-island canopy hoods.

The DOE fresh-air table also lists commercial, institutional, and industrial kitchens at 20 air changes per hour. This is a separate table from the hood-exhaust formula table, so do not mix the two unless the question tells you to compare room ventilation and hood exhaust.

Salvan's kitchen-ventilation discussion supports the practical distinction between exhaust fans, ducted hoods, ductless hoods, and self-venting ranges. A ducted hood removes cooking odors and stale air to the outside. Salvan also cautions that duct length, bends, and duct-size changes reduce efficiency and allow grease to collect. A ductless hood should be used only where outside venting is not possible, and it does not remove heat and humidity.

RA 9514 states that cooking equipment shall be protected by automatic kitchen hood fire suppression in accordance with internationally recognized standards. This is the local fire-safety anchor for questions that ask why a kitchen exhaust hood is not only an airflow device.

## Safe Answer Workflow

1. If the item gives a hood type and dimensions, use the DOE hood-exhaust formula table.
2. If the item asks about room ventilation for a commercial or institutional kitchen, use the DOE fresh-air table.
3. If the item asks about venting effectiveness, distinguish ducted hoods from ductless hoods using Salvan.
4. If the item asks about fire protection for cooking equipment, anchor the answer to RA 9514's automatic kitchen hood fire-suppression requirement.
5. Do not add unquoted duct gauges, cleaning intervals, or foreign code thresholds unless the question supplies them.

## Common Mistakes

- Using a room air-change value as if it were a hood-exhaust formula.
- Treating ductless hoods as equivalent to ducted hoods for heat and humidity removal.
- Ignoring fire suppression when the item is about protected cooking equipment.
- Choosing a single "CFM per foot" shortcut when the checked local table gives Q in relation to hood aperture area or hood length.
- Answering from restaurant rules when the prompt is only asking about basic hood styles.

## How It Is Tested

LEA-style items usually ask what makes a hood exhaust system effective, which DOE formula family applies, why outside venting matters, or what RA 9514 adds for protected cooking equipment. The safe answer follows the local source family named by the question.

## Checked Local Sources

- DOE Energy Conserving Design Guidelines, Type 1 hood styles, Table 6.2 hood exhaust formulas, and Table 6.8 kitchen fresh-air values.
- George Salvan, Architectural Utilities 2, kitchen ventilating equipment, ducted and ductless hood discussion, and practical duct-routing cautions.
- RA 9514 Revised IRR, cooking equipment protection by automatic kitchen hood fire suppression.
