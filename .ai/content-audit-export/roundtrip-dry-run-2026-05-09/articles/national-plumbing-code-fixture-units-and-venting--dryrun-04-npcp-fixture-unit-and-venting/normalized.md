# National Plumbing Code Fixture Units and Venting

## Learning objective

Given a utilities question prompt, use the Revised National Plumbing Code of the Philippines to distinguish fixture-unit load measurement from venting rules. The exam danger is treating plumbing terms as intuitive words. The Code uses them as technical controls.

## Governing source and provenance

For this topic, cite the source as the Revised National Plumbing Code of the Philippines adopted under PRC Board Resolution No. 04-99. The fixture-unit definition used here is Section 207.8, PDF p.24. The loop-or-circuit-vent definition is in the definitions section, PDF p.29. The vent-pipe prohibition is Section 311.4, PDF p.44. Use this source label consistently so the learner sees the Code provenance, not a vague “plumbing note.”

## Fixture unit is a load expression

Section 207.8 defines fixture unit as an arbitrary quantity used to express the load-producing effects or water requirements of different kinds of plumbing fixtures on the plumbing system. It then states that one fixture unit is equivalent to a rate of flow at 28.3 liters per minute, or 1 cubic foot per minute.

Source: Revised National Plumbing Code of the Philippines, PRC Board Resolution No. 04-99, Section 207.8, PDF p.24.

This definition has two exam consequences. First, fixture unit is not the physical count of fixtures. One fixture does not automatically equal one fixture unit. Second, fixture unit is not a pipe diameter by itself. It is a load scale that later supports sizing and design decisions. If the question asks for the equivalent flow rate, answer 28.3 liters per minute. If the question asks how fixture units function, answer that they express load-producing effects or water requirements.

## Do not import Fire Code numbers into plumbing

A common wrong answer borrows familiar numbers from other subjects. For example, 10.7 is a Fire Code egress illumination number, not the cited plumbing fixture-unit equivalent. In this topic, the plumbing value attached to one fixture unit is 28.3 L/min. Keep the subject area clean: plumbing load terms answer plumbing-load questions; fire-safety illumination terms answer means-of-egress questions.

## Venting is not spare drainage

Section 311.4 states that, except as provided in Sections 812, 813, and 814 of the Code, no vent pipe shall be used as a soil or waste pipe, and no soil or waste pipe shall be used as a vent. The same sentence also prohibits single drainage and venting systems with unvented branch lines.

Source: Revised National Plumbing Code of the Philippines, PRC Board Resolution No. 04-99, Section 311.4, PDF p.44.

The phrase “except as provided in Sections 812, 813, and 814” is important. It means the safe exam answer is not “never under any possible Code condition.” The correct answer is the Code’s prohibition with its cited exception path. If an option says a vent can become a waste pipe merely because it is oversized, short, convenient, or serving a small building, that option is not tracking Section 311.4.

## Loop or circuit vent location

The definitions section describes a loop or circuit vent as a vertical vent connection on a horizontal soil or waste pipe branch at a point downstream of the last fixture connection. It turns to a horizontal line above the highest overflow level of the highest fixture connected thereat. The terminus connects to the stack vent for loop venting or to the nearby vent stack for circuit venting.

Source: Revised National Plumbing Code of the Philippines, PRC Board Resolution No. 04-99, Definitions, Loop or Circuit Vent, PDF p.29.

This is a location rule, not just a name. If the prompt asks where the loop or circuit vent connects, the controlling phrase is downstream of the last fixture connection on a horizontal soil or waste branch. Do not choose an answer that places it upstream simply because the word “vent” sounds like it should start before the fixtures.

## Worked application

Suppose a problem statement says a designer wants to use a vent pipe as a backup waste pipe because the fixture branch is short. Section 311.4 rejects that reasoning unless the condition fits the Code sections specifically named as exceptions. The correct answer should preserve both halves of the rule: a vent pipe is not a soil or waste pipe, and a soil or waste pipe is not a vent, except as otherwise provided in Sections 812, 813, and 814.

Suppose another question asks for the fixture-unit flow equivalent. Do not compute from fixture count. The cited definition states the equivalent directly: one fixture unit equals 28.3 liters per minute, or 1 cubic foot per minute.

## Source-reading checklist

For this utilities topic, read the locator before reading the answer choices. Section 207.8 is a definition; it gives the meaning and flow-rate equivalent of fixture unit. Section 311.4 is a prohibition; it tells you what not to interchange between vent piping and soil or waste piping. The loop-or-circuit-vent entry is also a definition; it tells you where the connection occurs. A correct explanation should not blur these three source functions. Definition questions, prohibition questions, and location questions need different answers.

## Exam traps

- **Trap 1: fixture count equals fixture unit.** Fixture unit is a load expression, not a fixture tally.
- **Trap 2: vent pipe becomes waste pipe by convenience.** Section 311.4 does not allow that shortcut.
- **Trap 3: forgetting the named exceptions.** The answer should acknowledge Sections 812, 813, and 814 when the prohibition is quoted.
- **Trap 4: vague source label.** Use the Revised National Plumbing Code of the Philippines adopted under PRC Board Resolution No. 04-99.
