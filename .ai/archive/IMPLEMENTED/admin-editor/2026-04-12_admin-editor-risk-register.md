# Admin Editor Risk Register

| Risk | Cause | Impacted surface | Likelihood | Severity | Mitigation | Owner type | Detection method |
|---|---|---|---|---|---|---|---|
| Broken create flow persists | create/update orchestration remains split | `/admin/knowledge/new`, article CRUD | Medium | Critical | Phase 0 create-capable save path, integration test, manual smoke gate | frontend + backend | create flow e2e and editor telemetry |
| Taxonomy mapping still silently drops | save payload or action contract still omits node persistence | article editor, question coupling, coverage | Medium | Critical | explicit taxonomy save contract + persistence test + audit log | frontend + backend | integration test, audit records, post-save reload check |
| Status migration corrupts pipeline/review visibility | mixed old/new values or incomplete backfill | review queue, pipeline, dashboard | Medium | Critical | compatibility reads during migration, backfill script, migration test, shadow reports | backend / platform | migration diff report and UI smoke test |
| Article/question integrity gates block too much | validator rules overfit or are enabled too early | save/import/review/publish | Medium | High | warning-only shadow mode first, reason telemetry, per-gate kill switch | backend / product | validation warning dashboard and support feedback |
| Article/question integrity gates block too little | rule coverage incomplete or exception logic too broad | publish correctness, student question delivery | Medium | Critical | central validator reused everywhere, publish gate tests, unresolved-row report | backend / platform | publish gate metrics and sampled audits |
| Reviewer permissions remain contradictory | review workspace still tied to content-admin-only surfaces | `/admin/reviews`, review links | High | High | explicit reviewer-safe workspace and permission tests | frontend + backend | role-based e2e tests |
| Preview parity regresses | preview diverges from student renderer or serializer | `/admin/preview/*`, wiki render | Medium | High | single renderer truth, parity tests, feature flag for structured UI | frontend | preview parity regression suite |
| Preview access breaks after RLS change | policy migration does not match live roles | draft preview generation/open | Medium | High | update policy and keep service-role fallback ready | backend / platform | preview authorization smoke tests |
| Structured editor corrupts legacy MDX | parser or serializer rewrites unsupported content unsafely | article body, preview, publish | Medium | Critical | supported-block parser only, unsupported raw fallback, expert mode, round-trip tests | frontend / platform | sample corpus round-trip tests |
| Import normalization breaks old spreadsheets | canonical schema rejects or mis-maps legacy imports | import UI and batch question creation | High | High | dry-run import preview, compatibility fixtures, staged rollout | backend + frontend | import fixture tests and support telemetry |
| Mixed-content rollout creates unstable states | some articles use structured mode while validators/actions still assume raw-only behavior | authoring UI, preview, publish | Medium | High | phased feature flags, per-article fallback, shared serializer contract | frontend / platform | structured-mode fallback rate and error telemetry |
| Raw-MDX fallback bypasses validation | expert mode saves compile-invalid or uncoupled content | save/publish integrity | Low-Med | Critical | raw mode still uses compile + integrity validation before save/publish | frontend + backend | negative validation tests |
| Article-question backfill is incomplete | unresolved orphan questions remain after migration | standard question bank, publish gates | High | High | backfill report, manual remediation queue, publish blocking only after triage | backend / content ops | migration report and unresolved inventory |
| Student-facing delivery still serves unreadable-topic questions | delivery filters remain topic-only too long | wiki review quiz, prequestions, session delivery | Medium | High | tighten delivery filters after backfill and canonical status migration | backend | targeted delivery tests and sampled SQL audits |
| Legacy route/action cleanup breaks bookmarked/admin workflows | removal happens before canonical surfaces are fully stable | redirects, revalidation, staff habits | Medium | Medium | keep redirects, audit traffic, retire in Phase 5 only | frontend / platform | route hit monitoring and smoke tests |
| Audit trail misses critical mutations | taxonomy junction and review events not logged | compliance, rollback analysis, debugging | Medium | High | extend audit coverage and add action-level logs where triggers are insufficient | backend / platform | audit completeness checks |
| Save orchestration introduces new partial-failure states | staged save boundaries are incorrect | article/question/EI persistence | Medium | High | explicit dependency ordering, integration tests, partial-failure simulation | frontend + backend | save-path integration suite |
| Publish gate rollout causes editorial deadlock | too many existing records fail newly enforced rules | publish operations | Medium | High | warning-first rollout, remediation queue, phase gates, override policy | product + backend | publish-block telemetry |
