# 01_roadmap

Use this folder for active roadmap material: master roadmap, current phase, milestone tracker, dependency map, and sequencing guidance.

## Current mapped sources

- `.ai/plans/` contains active planning artifacts that inform roadmap work.
- `.ai/docs/00-meta/000-implementation-plan.md` captures an earlier documentation-system roadmap.
- `.ai/state/current-task.md` shows the current focus area but is not a full roadmap.
- `.ai/archive/IMPLEMENTED/` and `.ai/archive/SUPERSEDED/` preserve historical delivery outcomes and superseded planning lines.

## Current gap

There is no single current master roadmap file under the new taxonomy yet. Future roadmap creation should start here and reference preserved legacy planning sources rather than replacing them silently.
