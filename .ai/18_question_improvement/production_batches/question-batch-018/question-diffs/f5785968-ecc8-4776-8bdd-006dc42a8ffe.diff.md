## Added explanation

GIS stores current and historical data but its primary function is analysis, not archiving. GIS tools support CLUP preparation; they do not replace the CLUP itself. GIS is a spatial analysis tool that organizes planning data (land use zones, hazard maps, infrastructure networks, constraints) into layers that can be overlaid and analyzed to support planning decisions. GIS provides information for zoning; it does not eliminate the need for zoning ordinances.
