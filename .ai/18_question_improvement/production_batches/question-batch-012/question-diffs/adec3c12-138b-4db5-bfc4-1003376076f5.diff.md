Incorrect math; likely using incorrect divisors. This would be the result if using ACTUAL dimensions (8.25 BF and 3.5 BF) - however, delivery and trade are measured nominally. Calculation does not result in 450. Using standard NOMINAL board foot calculations for trade: (2×6×12)/12 = 12 BF per pc. 30 pcs × 12 = 360 BF. (2×4×8)/12 = 5.33 BF per pc. 40 pcs × 5.33 = 213.3 BF. Total = 360 + 213.3 = 573.3 BF. This exceeds the 450 BF requirement. Unless specified as 'actual volume', board feet for delivery/invoicing are always based on Nominal dimensions.
