## Added explanation

90° hooks are standard for non-seismic stirrups, not seismic confinement. Increasing extension to 12db does not make 90° hooks compliant for seismic design. 180° hooks are for longitudinal bar anchorage, not stirrups. Seismic column confinement hoops in SMRF frames must use 135° bend angle, not 90° (NSCP 12.13.5). This error (ERR-STRC-014) is one of the most common seismic mistakes. The 135° hook closes the loop more tightly and prevents bar buckling. Review the correct answer and associated code provision.
