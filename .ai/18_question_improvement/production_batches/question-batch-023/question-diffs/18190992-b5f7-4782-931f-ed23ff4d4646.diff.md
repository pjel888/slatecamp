## Added explanation

Program conflicts are adjacency issues, not BIM clashes. While structural analysis uses simulation, clash detection is geometry-based system coordination. Code compliance checking is separate from clash detection. Clash detection identifies system conflicts: a mechanical duct colliding with a structural beam, an electrical panel behind a plumbing access panel, etc. Catching these before construction saves time, cost, and field coordination problems.
