## Added explanation

This reverses the coal source and chemical composition. Class F comes from anthracite/bituminous (not lignite), and Class C comes from lignite/subbituminous (not anthracite). ASTM C618 specifies chemical composition requirements and pozzolanic reactivity, not only particle size. While fineness is a specification, the chemical differences between Class F and C are fundamental. Both Class F and Class C are acceptable for structural concrete when dosed within ASTM C618 limits. The difference in dosage reflects their chemical reactivity, not structural suitability. Class F fly ash (from anthracite/bituminous coal) is 50-70% silica and acts only as a pozzolan, replacing 15-25% cement. Class C (from lignite/subbituminous) contains 20-40% CaO, acts both as a pozzolan and self-cements, and is dosed at 20-35%. Both are suitable for structural concrete within their dosage limits. Class F and C fly ash have different chemical compositions, reactivity rates, and optimal dosage ranges. Candidates must match fly ash type to concrete strength requirements and durability goals.
