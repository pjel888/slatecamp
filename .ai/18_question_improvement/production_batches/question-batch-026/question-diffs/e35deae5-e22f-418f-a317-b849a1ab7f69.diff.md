## Added explanation

This describes the tenon, not the mortise. This describes a dado joint. This describes a rabbet joint. A mortise is a precisely chiseled rectangular cavity (hole) into which the matching tenon (protrusion) is inserted. Mortise = cavity (receptacle); Tenon = protrusion. Always pair these terms correctly.
