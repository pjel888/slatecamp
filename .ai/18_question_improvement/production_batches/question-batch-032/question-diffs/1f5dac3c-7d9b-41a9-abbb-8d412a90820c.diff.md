## Added explanation

50% snug-tight is still insufficient for primary connections; 70%+ is required for slip-critical behavior. 75% approaches code requirement but without strict calibration/verification, unreliability increases. 90% is the target for TC installation, not snug-tight. Snug-tight provides ~25% preload, generating minimal friction between connected surfaces. Under service loads, bolts slip, increasing deformation, vibration, and fatigue damage. For primary connections, snug-tight is inadequate; calibrated wrench (70%) or TC installation (90%) is required per RCSC Specification (adopted by NSCP C101-15).
