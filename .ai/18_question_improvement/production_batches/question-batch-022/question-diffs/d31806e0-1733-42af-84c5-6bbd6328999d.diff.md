## Added explanation

Wiegand-based local panels cannot track state across multiple readers without extensive inter-panel communication. Relay modules lack intelligence for credential-level anti-passback logic. OSDP's 200–500 ms polling interval creates a 0.4–1 second lag, allowing double-entry attempts to slip through before the system registers the first badge swipe at the exit. Motion sensors prevent tailgating (multiple people passing through one badge swipe) but do not prevent anti-passback (same person, same credential, multiple entries without exits). IP-based centralized systems with sub-second event reporting enable real-time anti-passback logic at the server. When a credential swipes at an entry reader, the server logs the event and blocks the same credential from being used at the same entry until an exit event is recorded. This requires centralized state management and low-latency communication. Anti-passback rules require real-time, centralized credential state management; legacy panel-based systems cannot enforce this due to polling delays and lack of inter-panel synchronization.
