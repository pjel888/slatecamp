## Added explanation

QoS ensures responsiveness but does not provide security. Isolation is not merely administrative convenience; it limits attack surface by preventing access control from being targeted by general-network malware. Isolation does not prevent WiFi interference (different frequency bands). VLAN tagging is a networking construct, not a security measure against command spoofing; encryption of commands is required. Network isolation complements firewalls but does not replace them. QoS is traffic prioritization, not cybersecurity; firewalls, IDS, and encrypted commands provide actual security controls. Isolated VLAN segregates access control traffic from general building LAN, reducing exposure to compromised endpoints. However, if the VLAN is breached (e.g., rogue device injected, network tap installed), encrypted command/response is critical to prevent an attacker from sending unencrypted 'unlock door' commands to readers or controllers. IP-based systems must use TLS/SSL encryption for all server-to-reader communication. Defense-in-depth requires network isolation (VLAN), firewall rules, and cryptographic protection of access control commands to mitigate IP-based system vulnerabilities.
