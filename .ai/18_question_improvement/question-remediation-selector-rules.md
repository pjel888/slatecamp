# Question Remediation Selector Rules

Strict v3 excludes existing meaningful explanations, repeated stems, duplicate/near-duplicate options, option-length giveaway risk, generic/meta distractors, missing answer keys, weak rationales, and insufficient linked-article support.

High-risk legal/code/professional-practice/dimensional questions are excluded unless item-level official source evidence is detected. Generic code_citation text, article title, linked-article existence, taxonomy node, broad source family, existing rationale text, AI source notes, and phrases such as BP 344 or PD 1096 alone are not sufficient. Evidence must include an official/source-pack/local-source signal and a locator such as section, rule, table, article, page, document code, source chunk ID, official URL/PDF, or equivalent locator tied to the item.

Expanded generic/meta leakage blocks phrases such as: which is not accurate, not accurate, misconception, ensuring all aspects, focusing on, formal directive, trap, outdated, different concept, ALE, exam trick, best answer is, incorrect because it is wrong, all of the above, and none of the above.
