# 05_logs

Use this folder for progress logs, validation logs, change logs, decision logs, and operational run notes.

## Current mapped sources

- `.ai/logs/changelog.md` is the preserved historical changelog.
- Runtime and state-adjacent notes also exist in `.ai/state/` and `.ai/ralph/`.

## Intent

Keep the preserved changelog intact. Add new focused operational logs here when a specific initiative needs its own traceable run record.
