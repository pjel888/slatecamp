# Feature Inventory

- adaptive quiz/testing modes (`quiz-v2`, testing hub, sessions, debrief)
- wiki + article reading + taxonomy-linked content
- notes and writing surfaces
- analytics dashboards and readiness visualization
- 3D Lab / spatial-learning modules

- developer docs, console, db, logs, test data
- protected CEO analytics/financial/team views
