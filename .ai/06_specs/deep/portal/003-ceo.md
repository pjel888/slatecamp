# CEO Portal

**Analysis Date:** 2026-04-06

## Overview

The CEO portal provides business intelligence and financial analytics for SlateCamp operations. It is gated to `ceo` and `super_admin` roles and lives under the `(protected)` route group, not a top-level segment.

**Route:** `/ceo`
**Access:** `profiles.role === 'ceo' | 'super_admin'`
**Location:** `src/app/(protected)/ceo/`
**Source:** `src/lib/queries/ceo/AGENTS.md`, `src/components/ceo/AGENTS.md`

## Page Count

4 pages.

## Authentication

Two auth patterns in `src/lib/queries/ceo/auth.ts`:

```typescript
// Server component auth — redirects on failure
verifyCeoAccess()

// Server action auth — throws on failure
assertCeoRole()
```

Both check `profiles.role` for `ceo` or `super_admin`.

**Source:** `src/lib/queries/ceo/auth.ts`

## Query Layer

Read-only queries in `src/lib/queries/ceo/`:

| File | Functions |
|------|-----------|
| `financial-queries.ts` | `getFinancialSummary()`, `getRevenueBreakdown()`, `getUnitEconomics()` |
| `team-queries.ts` | `getTeamMembers()`, `getDepartmentCosts()` |
| `user-queries.ts` | `getEngagementSnapshot()`, `getCohortRetention()`, `getChurnRiskSegments()`, `getTimeToValue()` |

**Source:** `src/lib/queries/ceo/`

## Materialized Views

User engagement data reads from `mv_engagement_snapshot` materialized view for performance, with fallback to live queries.

**Source:** `src/lib/queries/ceo/user-queries.ts`

## CEO Types

All financial and business types defined in `src/types/ceo.ts`:
- `FinancialSummary` — MRR, burn, net profit, runway
- `RevenueBreakdown` — Revenue by stream
- `UnitEconomics` — LTV, CAC, ARPU
- `TeamMember` — Team roster with role/department
- `EngagementSnapshot` — DAU/WAU/MAU metrics
- `CohortRow` — Cohort retention data
- `ChurnRiskSegment` — Churn risk by segment

**Source:** `src/types/ceo.ts`

## Currency

All financial amounts are in **Philippine Peso (PHP)**. Use `formatPeso()` from `src/types/ceo.ts` for all display formatting.

**Source:** `src/types/ceo.ts`
