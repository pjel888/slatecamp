WikiCard Stable

Card component for wiki article listings. Displays title, domain tag, status, and preview text.

PD 1096 Published
Section 401: Minimum Corridor Width Requirements
The minimum corridor width shall be 1.10 meters for residential and 1.50 meters for commercial occupancies under the National Building Code.
Updated Mar 18, 2026 · Egress Corridors
PropTypeDefaultReqDescription
titlestring—●Article title displayed as the card heading
descriptionstring——Preview snippet of the article content
domainstring—●Law or code domain (e.g., "PD 1096")
status'published' | 'draft' | 'archived''published'—Publication status badge
tagsstring[][]—Taxonomy tags for categorization
lastUpdatedstring——ISO date string for last update
hrefstring—●Navigation link for the full article
TSX
import { WikiCard } from '@/components/wiki/WikiCard'

export default function ArticleList() {
  return (
    <WikiCard
      title="Section 401: Minimum Corridor Width"
      domain="PD 1096"
      status="published"
      tags={['egress', 'corridors']}
      href="/wiki/pd-1096/section-401"
    />
  )
}
