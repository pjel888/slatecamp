# Decision 0004: No Live Content Mutation in MVP

## Decision

The MVP must not update `wiki_articles`, `questions`, or `design_scenario_questions` content.

## Rationale

This milestone is for monitoring and workflow control only. Content edits require correction proposals, source evidence, validation, and approval workflows that come later.

## Consequences

- Manual findings can be created.
- Statuses can be updated.
- Review decisions can be logged.
- Live educational content stays unchanged.

## Status

Accepted.
