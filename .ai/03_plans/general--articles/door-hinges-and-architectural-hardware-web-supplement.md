## Standards / association leads

- BHMA — `https://buildershardware.com/`
  - Use for: ANSI/BHMA standards families, hardware category vocabulary, Grade 1/2/3 performance concept.
  - Caution: full standards may be paywalled; do not quote detailed requirements unless directly verified.

- BHMA Certified Products Directory — `https://buildershardware.com/Certification-Program/Certified-Products-Directory`
  - Use for: category examples and certification terminology.
  - Caution: product listings change; not a design spec.

- ANSI/BHMA A156 standards overview — `https://buildershardware.com/ANSI-BHMA-Standards`
  - Use for: mapping hardware families to standards titles.
  - Caution: standards titles are not detailed requirements.

- Door and Hardware Institute — `https://www.dhi.org/`
  - Use for: hardware schedule, opening, architectural hardware consultant vocabulary.
  - Caution: many resources may be course/member-only.

- Steel Door Institute — `https://www.steeldoor.org/`
  - Use for: hollow metal door/frame preparation, hinge reinforcement, strike preparation, handing.
  - Caution: steel-door-specific.

## Manufacturer technical leads

- Allegion — `https://www.allegion.com/`
  - Use for: lock functions, exit devices, closers, terminology.
  - Caution: manufacturer/product-oriented; verify code statements separately.

- I Dig Hardware — `https://idighardware.com/`
  - Use for: clear explanations of hardware functions, egress/accessibility cautions, fire-door vocabulary.
  - Caution: blog/source of interpretation; use as explanatory support, not primary authority.

- ASSA ABLOY Door Security Solutions — `https://www.assaabloydss.com/`
  - Use for: hardware sets, openings, trim/cylinders/mullions/access-control terminology.
  - Caution: proprietary product language.

- Hager Companies — `https://www.hagerco.com/`
  - Use for: full-mortise/half-mortise/full-surface hinges, continuous hinges, NRP, bearing types.
  - Caution: product-specific dimensions and load charts.

- McKinney / ASSA ABLOY — `https://www.assaabloydooraccessories.us/en/products/hinges/mckinney/`
  - Use for: architectural hinge application terms, standard vs heavy weight, ball bearing, wide throw, swing clear.
  - Caution: product catalog; corroborate generic terms.

- SOSS — `https://www.soss.com/`
  - Use for: concealed/invisible hinge examples and visual geometry.
  - Caution: brand name is not the generic term.

- Sugatsune — `https://www.sugatsune.com/`
  - Use for: specialty concealed/pivot/soft-close hinges, especially visual recognition.
  - Caution: many items are cabinet/furniture hardware.

- dormakaba — `https://www.dormakaba.com/`
  - Use for: door closers, exit devices, access control, glass door hardware.
  - Caution: product-specific adjustment terms.

- LCN / Allegion — `https://www.allegion.com/us/en/brands/lcn.html`
  - Use for: closer terminology — regular arm, parallel arm, top jamb, sweep, latch speed, backcheck.
  - Caution: closer-specific; not hinge source.

- Norton Rixson / ASSA ABLOY door controls — `https://www.assaabloydooraccessories.us/en/products/door-controls/`
  - Use for: center-hung/offset/intermediate pivots, floor closers, overhead concealed closers.
  - Caution: product-specific capacities.

## Accessibility / egress / fire-life-safety context leads

These are useful for concepts, not Philippine legal claims unless matched to local sources.

- U.S. Access Board ADA Guides — `https://www.access-board.gov/ada/`
  - Use for: operable parts, grasping/pinching/twisting concepts, thresholds, clear opening concepts.
  - Caution: U.S. federal accessibility source; not Philippine law.

- ICC — `https://www.iccsafe.org/`
  - Use for: model-code accessibility and door concepts.
  - Caution: U.S./model-code context.

- NFPA — `https://www.nfpa.org/`
  - Use for: egress/fire-door terminology: self-closing, self-latching, panic/fire exit hardware.
  - Caution: full standards are controlled; do not quote requirements without verified accessible text.

- UL Solutions — `https://www.ul.com/`
  - Use for: listed/classified/labeled hardware and assembly concepts.
  - Caution: listing is product-specific.

- Intertek Warnock Hersey — `https://www.intertek.com/`
  - Use for: testing/certification terminology.
  - Caution: certification data is product-specific.
