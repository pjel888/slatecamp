01 / Scattered review

It is not just that there is too much to study.

The harder part is not knowing where a topic belongs, whether the source is current, or what to revisit after practice exposes a gap.

Codes and tables blur together.Rules need context, not only memorized numbers.
PDFs and recordings pile up.More files can create more pangangapa.
Mock boards expose gaps late.A miss should become a next step.
Familiar can feel like mastered.Practice separates recognition from understanding.
The real need is orientation.A reliable map makes the next pass calmer.
02 / Atlas model

Turn scattered architecture knowledge into routes.

SlateCamp should show a repeatable loop: find the topic, understand where it fits, check what stayed, and return to what needs another pass.
