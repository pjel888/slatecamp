## Classification Legend

| Classification | Meaning | Can it be used as a grounding source? |
|---|---|---|
| `SOURCE_OF_TRUTH` | Canonical data exported directly from Supabase or generated by deterministic pipeline. Hash-verifiable. | **YES — primary grounding source** |
| `DERIVED_EXPORT` | Transformed from source-of-truth by deterministic code. Preserves traceability to original. | **YES — with caveat (trace to original)** |
| `GENERATED_REPORT` | Analysis/summary output from a pipeline run. Not source data but has run-level traceability. | **NO — for reference only. Do not ground facts on reports.** |
| `DEBUG_ARTIFACT` | Output of ad-hoc debug scripts or one-off operations. No stable provenance. | **NO — unstable, may contain test data** |
| `REVIEW_ARTIFACT` | Human or AI review output. Contains judgments and flags, not source facts. | **NO — for editorial workflow only. Do not use as factual source.** |
| `STALE_OR_UNKNOWN` | Artifact whose relationship to current state is unclear. May be from superseded runs. | **NO — provenance unverifiable for current state** |
| `PLANNING_DOC` | Planning, roadmap, or design document. Not data. | **NO — planning context only** |
| `DO_NOT_USE_AS_GROUNDING_SOURCE` | Explicitly marked as unsuitable for grounding, regardless of other classifications. | **ABSOLUTELY NOT** |

## Provenance Freshness Caveat

This artifact map is based on the local export snapshot. It does not prove live Supabase has not changed since export.

Critical Phase 1A inconsistency to resolve:

- `export-summary.json` reports `parser_status: "not_started"` and `ui_block_count: 0` across all 567 articles.
- Per-article bundle artifacts include populated `normalized.md` and `ui-blocks.json` files from later roundtrip work.
- Therefore, `export-summary.json` may be authoritative for exported article/question/source counts and hashes, but not currently safe for UI-block complexity, parser-state, or component-complexity decisions until reconciled.

## Key Finding: Source Coverage Gap

From `export-summary.json`:
- 567 articles exported
- 1,110 total sources across all articles (average ~2 per article)
- Many articles have `source_count: 0` or `source_count: 4` (the default seeding count)
- The fact-checking tracker confirms widespread `MISSING_CITATION — sources.json empty` flags

**This is the single largest data quality issue for source-grounding.** Before the pipeline can ground AI-proposed changes against sources, the source coverage must be improved.
