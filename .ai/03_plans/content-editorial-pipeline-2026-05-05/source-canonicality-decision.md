# Source Canonicality Decision — Phase 0.5

**Date:** 2026-05-05
**Scope:** Classify every potential source structure in the SlateCamp repo/DB as a canonical candidate, supporting context, authoring brief, derived artifact, not-a-source, or unknown.
**Authority:** This document is a planning decision, not a source pack. It does not create embeddings or run AI rewriting.

---

## Classification Legend

| Classification | Meaning | Can ground AI-proposed factual changes? |
|---|---|---|
| `DISCOVERY_SEED_ONLY` | Citation labels/metadata can seed source discovery, but are not source truth and cannot ground claims. | **No — discovery only** |
| `CANONICAL_SOURCE_CANDIDATE` | Could become a primary source pack after official text, provenance, verification, versioning, and chunking. | **Potential — only after Phase 0.5 proof** |
| `SUPPORTING_CONTEXT_ONLY` | Provides metadata, discovery, or navigation but does not contain verifiable source text excerpts. | **No — use for discovery only** |
| `AUTHORING_BRIEF_ONLY` | Written by authors/editors as guidance; not an official legal/code/textual source. | **No — do not ground claims on editorial guidance** |
| `DERIVED_ARTIFACT_ONLY` | Generated by previous pipeline runs, batch processing, or AI output. Not primary. | **No — may contain hallucinated or stale claims** |
| `NOT_A_SOURCE` | Explicitly not a source for factual grounding (e.g., UI configs, run logs, planning docs). | **No** |
| `UNKNOWN` | Provenance unverifiable; treat as missing until proven otherwise. | **No** |

## 1. wiki_article_sources (1,110 rows live)

**Classification:** `DISCOVERY_SEED_ONLY` with major reservations

**Decision:** `wiki_article_sources` can be treated as a **source-discovery seed**, but it **cannot be treated as a canonical source candidate or approved source pack** in its current form.

**Rationale:**
- 1,110 live rows exist, exported in bundle `sources.json` files.
- Each row has: `label`, `url`, `source_type` (TAXONOMY_SOURCE_TYPE), `description`, `is_verified` (default FALSE), `sort_order`.
- The `is_verified` flag defaults to FALSE across the corpus; most rows are unverified.
- Current local export evidence shows `url: null` for all 1,110 exported rows; labels exist but URLs are not populated in the export snapshot.
- These are **article-scoped citation rows**, not **claim-addressable source packs**.
- No source text excerpt is stored. No version/hash. No page/section locator.

**Permitted use:**
- Seed source-pack discovery ("these are the URLs/articles we already reference").
- Generate a source-needs report ("these articles have zero source rows").
- Cross-check against external official URLs for availability.

**Prohibited use:**
- Do not treat `wiki_article_sources` rows as proof that a factual claim is correct.
- Do not use `description` or `label` as source text for claim grounding.
- Do not assume `url` is populated or resolves to the current official version.

**Phase 0.5 requirement:**
- For each high-risk cluster (PD 1096, BP 344, RA 9514, RA 9266, contracts/SPP), decide whether `wiki_article_sources` rows can seed a proper source pack or whether a new primary source pack must be built from external PDFs.

## 4. wiki_articles.content (567 rows)

**Classification:** `AUTHORING_BRIEF_ONLY` / `DERIVED_ARTIFACT_ONLY`

**Decision:** `wiki_articles.content` is the **current baseline prose** for each article, but it is **not a canonical primary source**.

**Rationale:**
- This is editorial content written for learners, not official legal/code text.
- It may contain paraphrases, simplifications, or pedagogical framings that differ from official sources.
- It is useful as the **rewrite baseline** (what the article currently says) and for **fact-preservation comparison**.
- It is NOT suitable as the authority for whether a legal claim is correct.
- Historical fact-checking flags (`MISSING_CITATION`, `Wrong section references`) confirm that article prose has contained errors.

**Permitted use:**
- Baseline for diff/comparison only; the baseline may itself contain factual errors.
- Input to claim-extraction for source-needed analysis.
- Source for "original-preserved" marking when no official source is available.
- Fact-preservation comparison must verify against an approved source pack, not assume baseline correctness.

**Prohibited use:**
- Do not cite `wiki_articles.content` as proof that a legal/code claim is correct.
- Do not use it to validate answer keys or code citations in questions.

**Classification:** `SUPPORTING_CONTEXT_ONLY` / `UNKNOWN`

**Decision:** `questions.code_citation` is **supporting context** when present, but its accuracy is **unverified**.

- It is author-entered metadata, not extracted from an approved source pack.

**Permitted use:**

- Flagging questions that lack citations.
- Pilot selection for high-risk legal/code clusters.

**Prohibited use:**
- Do not treat `code_citation` as verified source text.
- Do not use it as the sole authority for answer-key correctness.

## 6. questions.rationale (JSONB, 7,159 rows)

**Classification:** `DERIVED_ARTIFACT_ONLY`

**Decision:** Rationales are **pipeline outputs** (author or AI generated), not primary sources.

**Rationale:**
- Rationales explain why an answer is correct; they do not prove it.
- They are subject to the same risks as article prose: paraphrase, simplification, potential error.
- The question-bank failure-mode map identifies `rationale contradicts answer key` as a CRITICAL risk.

**Permitted use:**
- Pedagogy review.
- Contradiction detection against answer keys.
- Source-needed analysis (does the rationale cite an official source?).

**Prohibited use:**
- Do not ground factual claims on rationale text.

## Decision Gate

Before Phase 1B can begin:

1. **At least one approved source pack** must exist for a high-coverage official source (e.g., PD 1096 IRR).
2. **Live `wiki_article_sources` verification status** must be audited against the current database and compared to local export evidence: local export currently shows 1,110/1,110 `is_verified: false` and 0 populated URLs.
3. **`taxonomy_sources` contradiction** must be resolved: why does the comment claim completeness at 0 rows?
4. **No source structure currently in the repo** can be used as the sole authority for AI-proposed factual changes.

**Verdict:** Source canonicality is **unresolved**. The pipeline has discovery seeds (`wiki_article_sources`) but no approved primary source packs.
