# What Not To Build Yet

This file is intentionally explicit to prevent scope creep.

Do not build:

- Kimi integration.
- Qwen integration.
- DeepSeek integration.
- OpenAI integration.
- Perplexity integration.
- Valyu integration.
- Web search.
- RAG/source retrieval.
- Embedding generation.
- AI prompt editor.
- Batch AI jobs.
- Token/cost dashboards.
- Automatic correction proposals.
- Automatic publishing.
- Source ingestion.
- Article/question diff editor.
- Content versioning beyond audit proposal logs.

The task is only:

```text
Admin UI + audit workflow/logging foundation.
```

Future AI workers should be able to write into this foundation later.
