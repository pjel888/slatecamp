# Status Copy Reference

Use this as the single source for status/phase descriptions in the UI.

## Phases

| Phase | User-facing description |
|---|---|
| Not started | This item has not entered the audit workflow. |
| Tier 0 static | Basic no-AI structural checks have run. |
| Tier 1 flag scan | Future AI flag-only scan phase. Not active in MVP. |
| Source verification | Future source-backed verification phase. Not active in MVP. |
| Correction proposed | A correction or content-change proposal exists. |
| Validation | Future independent validation phase. Not active in MVP. |
| Human review | A human/admin reviewer needs to review or is reviewing this item. |
| Approved | A human/admin reviewer approved the item/proposal. |
| Published | The approved change has been applied/published. Not active in MVP. |

## Statuses

| Status | User-facing description |
|---|---|
| Not checked | No audit phase has been completed. |
| Passed current phase | No issue was recorded in the current phase. |
| Flagged | A potential issue has been recorded. |
| Needs source check | The item needs verification against sources. |
| Likely issue | A potentially significant issue has been recorded. |
| Confirmed issue | A reviewer or future verification step confirmed an issue. |
| Correction proposed | A change proposal exists and needs review. |
| Validated | A future validation phase passed. |
| Needs review | Human/admin review is required. |
| Approved | Human/admin approval has been recorded. |
| Published | Approved change has been applied/published. |
| Rejected | Finding/proposal was rejected. |
| Skipped | Item was intentionally skipped. |
| Failed | The audit/check failed. |
