Turn the `.ai/08_prompts/` pack into a durable repo-intelligence operating system by pairing each prompt category with stable audits, plans, tasks, state summaries, and prompt-library files.

1. **Truth capture** — stable audits and state summaries for architecture, features, performance, backend, frontend, docs, and agents.
2. **Navigation** — route/feature/data-flow/frontend execution specs and architecture maps.
3. **Execution support** — task packs and remediation plans per domain.
4. **Prompt normalization** — reusable prompt files with stable names and clear purpose.
5. **Governance** — durable agent-system map and doc drift tracking.

## Sequencing

- Link them from roadmap/state/README surfaces
- Keep historical date-stamped docs intact
- Leave product-code refactors for follow-up execution lanes
