# National Plumbing Code Fixture Units and Venting

## Learning objective

Use the National Plumbing Code definition of fixture unit and the Code rule on vent piping to avoid common utilities distractors.

## Fixture unit is a load measure

The Revised National Plumbing Code defines fixture unit as an arbitrary quantity used to express the load-producing effects or water requirements of different plumbing fixtures. One fixture unit is equivalent to a rate of flow at 28.3 liters per minute (1 cu. ft./minute).

Source: Revised National Plumbing Code of the Philippines, Section 207.8, Fixture Unit, PDF p.24, extracted from `vitruvius-connection/001_Raw-Source-Layer/005-Utilities/Revised National Plumbing Code of the Philippines.pdf`.

## Venting is not spare drainage

The same Code prohibits using a vent pipe as a soil or waste pipe, and prohibits using a soil or waste pipe as a vent, except as otherwise provided in Sections 812, 813, and 814. It also states that single drainage and venting systems with unvented branch lines are prohibited.

Source: Revised National Plumbing Code of the Philippines, Section 311.4, PDF p.44.

## Loop or circuit vent

A loop or circuit vent is a vertical vent connection on a horizontal soil or waste branch downstream of the last fixture connection, turning to a horizontal line above the highest overflow level of the highest connected fixture.

Source: Revised National Plumbing Code of the Philippines, Definitions, Loop or Circuit Vent, PDF p.29.

## Board shortcut

If a utilities question treats fixture unit as a physical fixture count, reject it. If a venting question treats a vent pipe as a convenient substitute waste line without citing an exception, reject it. The Code language is about system function, not pipe-count shortcuts.
