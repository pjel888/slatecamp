## Core positioning

SlateCamp is an **architecture knowledge atlas / resource platform**, not primarily a study tool.

Public category language:

- `Architecture knowledge atlas`
- `Architecture knowledge resource platform`
- `Field guide for architecture knowledge`

Internal metaphor only:

- `Pokedex-style buddy`

Do not use public `Pokedex/Pokédex` copy unless explicitly approved.

## Hero direction

Use the **SlateCamp Atlas Field**:

- transparent R3F/Three canvas blended into the dotted-grid hero background;
- floating sheet stack / blueprint planes;
- constellation-like knowledge nodes;
- scattered-to-mapped knowledge motion;
- calm, premium, reassuring, architecture-evocative;
- no black container;
- no mini-tool interface;
- no setback-slider hero as default;
- no feature cards above the fold.

## Copy stance

Students do not primarily care about SRS, active recall, quiz algorithms, IRT, taxonomy heatmaps, or internal mechanics.

They care about:

- assurance;
- comfort;
- reliability;
- source-backed knowledge;
- knowing what they do and do not understand;
- feeling less lost between school, board-review season, and self-study.

## Value stance

Public copy should stay focused on what happens to the user after using SlateCamp:

- scattered architecture knowledge becomes mapped;
- unclear rules become visual and understandable;
- weak topics become easier to find;
- next study actions become calmer and more obvious;
- the student feels less lost and more prepared.

Avoid public comparison copy. Do not mention adjacent institutions or competitors unless Philip explicitly asks for comparison messaging.

## Package policy

Use the existing stack plus `maath` for the hero motion system:

- Next.js / React / Tailwind;
- `three`;
- `@react-three/fiber`;
- `@react-three/drei`;
- `framer-motion`;
- `@use-gesture/react`;
- `maath` for R3F damped motion smoothing.

Do not add these for the live hero first pass:

- GSAP;
- Remotion;
- Spline runtime;
- Theatre.js;
- Leva public UI;
- postprocessing stack.

## Superseded docs

Older landing docs may still contain `study companion`, `readiness engine`, `Setback Explorer`, or `Your architecture study companion` language. Treat those as historical unless explicitly needed for legal/CTA/gating checks.
