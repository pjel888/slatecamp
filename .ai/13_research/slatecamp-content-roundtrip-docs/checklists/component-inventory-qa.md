# Component Inventory QA Checklist

- [ ] `.tsx` files are scanned.
- [ ] Named exports are detected.
- [ ] Default exports are detected.
- [ ] Props names are inferred where possible.
- [ ] Article usage is matched against inventory.
- [ ] Unknown article components are reported.
- [ ] Components likely embeddable in articles are identified with reasons.
- [ ] No source files are modified.
