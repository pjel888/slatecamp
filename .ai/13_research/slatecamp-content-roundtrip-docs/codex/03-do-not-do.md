# Do Not Do

Do not:

```text
- integrate AI APIs
- fact-check content
- rewrite articles automatically
- delete custom UI blocks
- convert custom UI into plain prose permanently
- mutate wiki_articles during export/normalize/compose/diff
- update questions during article push
- push without stale hash check
- push without --apply
- hardcode component names instead of scanning repo
- assume all articles are plain markdown
- assume all components are valid article embeds
```
