# Export Bundle Format

Each article should export as a self-contained folder.

## Folder structure

```text
.ai/content-audit-export/
  manifest.json
  sync-state.json
  articles/
    <safe-slug-or-article-id>/
      original.md
      normalized.md
      candidate.md
      ui-blocks.json
      article-metadata.json
      linked-questions.json
      sources.json
      taxonomy.json
      component-usage.json
      diff-report.json
```

## `original.md`

Exact value of `wiki_articles.content`.

Rules:

```text
- Do not alter whitespace.
- Do not normalize line endings unless the implementation explicitly records it.
- Do not remove custom UI.
- Do not add comments.
```

## `normalized.md`

AI/human-readable markdown with custom UI blocks replaced by safe placeholders.

Example:

```md
# BP 344 Ramps

Ramps must be designed for accessible movement.

[UI_BLOCK id="ui_003" component="RampSlopeExplorer"]
summary: Interactive ramp slope widget.
textual_payload: Demonstrates slope and width cases.
[/UI_BLOCK]
```

## `ui-blocks.json`

Structured preservation of every removed custom UI block.

Includes:

```text
block_id
component_name
raw
start_offset
end_offset
props_text
props_json if parseable
children_raw
children_text
placeholder
```

## `candidate.md`

Generated by compose step. It should not exist until composition has been run, or it should be regenerated every time.

## `article-metadata.json`

Contains article identity and hashes.

## `linked-questions.json`

Contains all `questions` where `questions.article_id = article_id`.

## `sources.json`

Contains all `wiki_article_sources` where `wiki_article_sources.article_id = article_id`.

## `taxonomy.json`

Contains rows from `wiki_article_taxonomy` and joined taxonomy node data from `taxonomy_tree`.
