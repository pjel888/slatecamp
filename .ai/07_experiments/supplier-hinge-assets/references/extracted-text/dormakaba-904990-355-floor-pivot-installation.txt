Installation Instructions
355.5 Floor Pivot
1.1	
Using a plumb bob, align header spindle with bottom 
pivot spindle.
1.2	 Mark and drill holes, and recess in flooring surface.
•	
Recess: 1-1/2” [38] deep x 3/8” [10] diameter recess
•	
Wood Floors: 1/8” [3] drill bit.
•	
Concrete Floors: Drill 1” [25] deep holes, using 1/4” [6] 
drill bit.
1.3	 Insert anchors, if necessary.
1.4	 Ensure pivot is aligned and plumb.
1.5	 Slide gasket onto pivot extention.
1.6	 Secure floor bearing with included fasteners.
