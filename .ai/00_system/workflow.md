# .ai Standard Workflow

**Last Updated:** 2026-04-16

## Standard operational loop

```text
research pack → audit → implementation plan → task breakdown → execution → validation → state update → archive if superseded
```

## Detailed flow

1. **Research pack**
   - Gather context, prior decisions, external findings, and relevant existing docs.
2. **Audit**
   - Inspect the current state before proposing structure or implementation changes.
3. **Implementation plan**
   - Document scope, constraints, sequencing, and non-destructive migration choices.
4. **Task breakdown**
   - Convert the plan into actionable packets, checklists, or work queues.
5. **Execution**
   - Make additive, traceable changes.
6. **Validation**
   - Confirm the intended structure exists and that no protected work was lost.
7. **State update**
   - Record current status, blockers, recommendations, and active references.
8. **Archive if superseded**
   - Archive intentionally with traceability. Archive is preservation, not deletion.

## Guardrails

- Audit first.
- Prefer indexing over moving.
- Never silently delete history.
- Keep source-of-truth and legacy/reference material clearly labeled.
